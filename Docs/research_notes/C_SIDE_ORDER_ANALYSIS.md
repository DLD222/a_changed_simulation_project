# 米氏收敛阶为什么还不到 2：误差源分解与修正方法

<!-- SPDX-License-Identifier: BSD-3-Clause -->


> 日期：2026-10-31 · 对象：TE 米氏（PEC 圆柱 R=1、λ=1、单 grid、40/80/160 三档）
> 现状：掩膜 Yee 近场 **1.28**、C 侧共形 E **1.06**，RCS 1.76 / 1.77。
> 本文只回答一个问题：**为什么不是 2**，以及**改什么才有用**。含一组新的纯几何实验（§3.2）。

---

## 0. 结论先行

1. **不是"共形方法到不了二阶"**，而是当前 `Lx`/`Lz` 的构造方式**天生一阶**：
   任何"用相邻 cell 的分数去平均格心线上的开放长度"的做法（方案 B 的面积分数、方案 A 的面分数）
   实测阶数都是 **1.4–1.5**，且**方案 A 比方案 B 还差**（§3.2）。
2. **`A_y` 不是瓶颈**：它已经是 **2.4 阶**（`¼dxdzΣvolfrac` 是维度匹配的中点积分）。
3. **掩膜不是"阶数瓶颈"，但 F3 的放开方式必须回退**：`ly==0 → A_y<=0` 会让 PEC 内出现
   持续热斑（`max|Ey|` 1.68e6 → **7.13e6**，PEC 内从 **0** 变到 7.1e6），而环带 L2 完全看不见。
   已回退为 `ly` 判据，把 `A_stab` 只作为分母下限保留（§3.4）。
4. **唯一能到二阶的路径是 level-set 精确求交**（方案 C），不是方案 A。
5. 还有一层**测量地板**：真空对照的入射波残差在 160² 仍有 **15%**，它直接进入 L2，并且污染 RCS
   （RCS 减的是解析入射而不是同分辨率的数值入射）。

## 3. 逐项量化

### 3.1 `A_y` 是二阶（排除 E2）

`A_y(i,j) = ¼ dx dz Σ_{4 cells} volfrac`。这是"节点周围四个象限的面积加权"，与面积同量纲，
属于标准的二维中点积分 → 二阶。

纯几何实验（解析圆、精确 `volfrac`、三档）给出 **2.39 / 2.42** 的阶（§3.2 表），
与 CHECK 的 1.97 同属"二阶"（差异来自统计口径，见 §3.2 注）。

**结论**：`A_y` 不需要改。

### 3.2 `Lx`/`Lz` 是一阶，而且换面分数也不会变成二阶（关键实验）

纯几何实验（`/tmp/geom_order.py`）：域 `[-4,4]²`、PEC 圆 `R=1`、`n = 40/80/160`，
用解析圆 + 精确 `volfrac`/面分数，比较三种构造与**精确的格心线开放长度**：

| `n` | `h` | 方案 B RMS (m) | 方案 A RMS (m) | `A_y` RMS (m²) |
|---|---|---|---|---|
| 40 | 0.2000 | 0.02864 | 0.02946 | 6.887e-03 |
| 80 | 0.1000 | 0.01415 | 0.01443 | 1.315e-03 |
| 160 | 0.0500 | 0.00835 | 0.00932 | 2.454e-04 |
| **阶** | | **1.02 / 0.76** | **1.03 / 0.63** | **2.39 / 2.42** |

> **2026-10-31 更正**（`C_SIDE_ORDER_ANALYSIS_REVIEW.md` §2）：上表已改为**对偶线的正确位置**。
> 初版把 `Lx` 放在格心线（`x_i` 取格心，积分跨整格），而代码里 `Lx` 在 `Bx` 位置（`x_i` 是节点，
> 对偶线跨半个 cell + 半个 cell），两者差半格。初版数字（0.0412/0.0160/0.0058，阶 1.4–1.5）
> 是错位统计，不能当几何基线。更正后：**B 与 A 都是一阶（~1.0），A 仍略差**，与仿真观测的
> 1.06–1.28 更自洽。

其中
- 方案 B：`Lx = ½h(v(i-1,j)+v(i,j))`（当前实现）
- 方案 A：`Lx = ¼h(az(i-1,j)+az(i-1,j+1)+az(i,j)+az(i,j+1))`（四面平均的面分数，DESIGN2 §1.5 的"修正版 A"）

**三条结论**：

1. **方案 A 不比方案 B 好**——RMS 反而大约 15%，阶数一样。原因是两者都在"用相邻 cell 的
   平均去估一条格心线上的长度"，而 cell 内边界的位置（不是分数）才是决定量；
2. **一阶的上限是这类"平均"方法的固有属性**，不是索引或实现错误；
3. 想真正到二阶，必须让 `Lx/Lz` 变成**沿格心线与边界求交的精确积分**（方案 C，level set）。

> 口径说明：CHECK 报的 `Lx` RMS 是 0.097/0.048/0.027（阶 1.0），本文是 0.041/0.016/0.006（阶 1.4）。
> 差异来自两点：(a) 本文只统计"邻域内有 cut cell"的点，避免未切割点的零误差稀释 RMS；
> (b) CHECK 的"精确值"可能用了不同的归一化。**两者的一阶结论一致**，绝对值不应直接比较。

### 3.3 测量地板与 RCS（E5/E6）

真空对照（EB 移出域外、同一激光源、同一三档），对 `exp(−iKz)` 做最小二乘平面波拟合，
残差（相对幅度）：

| `n` | 40 | 80 | 160 |
|---|---|---|---|
| 真空残差 | 0.828 | 0.210 | **0.147** |

即：**没有散射体**时，160² 的数值入射波与解析平面波仍差 15%。来源候选：数值色散
（`k_num ≠ K`，在 5λ 的拟合窗上积累相位）、激光源开启过程、PML 边缘。

误差预算 @160²（C 侧）：

```
总 L2        = 0.4395
真空地板     = 0.147      (33%)
正交扣除后   = 0.413      (67%，来自边界层 + 色散 + 拾取)
```

所以"扣掉地板后仍远大于地板"→ **物理误差主导，不是被地板淹没**。但地板会随 dx 变化，
如果地板下降得比物理误差快，拟合阶数会被抬高（或压低），三点拟合不可靠。

RCS 更糟：`Asc = A_al − exp(iKZ)` 减的是**解析**入射，于是把入射波的色散相位误差
当成散射场。RCS 阶数 1.76 里有一部分是这个伪影。

### 3.4 掩膜（E3）：不是"瓶颈"，但 F3 引入了 PEC 内热斑（指标盲区）

初版写"F3 后 L3 与米氏结果逐位不变 → 掩膜不是瓶颈"。**这个论证不成立**
（`C_SIDE_ORDER_ANALYSIS_REVIEW.md` §3）：环带 L2 取 `1.5R–2.5R`，而 F3 放开的是
`A_y > 0` 但很小的节点，它们在 PEC 内（`r ≈ 0.86`）形成**持续热斑**：

| 量（米氏 TE 80²，末帧） | F3 前（`ly` 判据） | F3 后（`A_y<=0`） |
|---|---|---|
| `max|Ey|`（全网格） | 1.68e6 | **7.13e6**（在 PEC 内） |
| 环带 L2（1.5R–2.5R） | 0.9321 | 0.9321（4 位一致，**看不见热斑**） |
| L3 45° | `r = −1.0459` | 同左（4 位一致） |

即：**L2 环带指标对 PEC 内热斑是盲区**，"L2 不变"不能推出"场不变"。

本轮的 `A_stab` 扫描（`algo.ect_conformal_E_Astab`，单位 `dx*dz`，米氏 80² 末帧）：

| `A_stab` | 全网格 `max|Ey|` | PEC 内（`r<0.9`） | 环带（1.5R–2.5R） |
|---|---|---|---|
| 0.001 | 7.13e6 | 7.13e6 | 1.66e6 |
| 0.1（默认） | 6.89e6 | 6.89e6 | 1.66e6 |
| 0.5 | 4.05e6 | 2.40e6 | 1.66e6 |
| 2.0 | 2.87e6 | 1.34e6 | 2.62e6 |
| 10.0 | 3.47e6 | **1.84e5** | 2.12e6 |

**结论**：
1. 热斑确实由小 `A_y` 的 `1/A_y` 放大引起，但**要把 PEC 内压到 1e5 量级需要 `A_stab ≈ 10`**，
   此时环带的场已经被抬高 27%（1.66e6 → 2.12e6），等于**放弃共形、退化为阶梯**；
2. 只抬 `A_y` 分母的"半侧稳定化"**不足以**支撑"放开 cut 节点"；
3. 因此顺序必须是：**先做完整的对偶稳定化（或保持 `ly` 掩膜不放开）→ 再 level-set**。
   F3 的"放开掩膜"在完整稳定化之前应当**回退或加 `A_y <= A_stab` 二次门限**。

## 4. 为什么"共形 FDTD 应该二阶"的直觉在这里失效

Dey–Mittra 的二阶性依赖于：**对偶量的每一对（面面积 / 边长度）都来自同一个精确的几何剖分**，
使离散 Hodge star 与连续 Hodge star 在二阶精度内一致。

当前实现满足"Hodge star 成对"（E 侧有 `A_y/Lx/Lz`，B 侧有 `face_areas/edge_lengths`），
但**两对几何量不是从同一个精确剖分导出的**：

| 侧 | 量 | 来源 | 精度 |
|---|---|---|---|
| B | `face_areas` | `getAreaFrac()`（AMReX 精确） | 精确 |
| B | `edge_lengths` | `getEdgeCent()` + 判据 | 精确 |
| E | `A_y` | `¼Σvolfrac` | 2 阶 |
| E | `Lx`/`Lz` | **相邻 cell 分数平均** | **1 阶** |

所以离散系统的"能量配对"误差是一阶的，整体场误差被压在一阶。
这正是 `C_SIDE_RESEARCH2.md` §3.2 说的"不同源"，只是当时没有量化。

## 5. 修正方法（按有效性排序）

### 5.0 先决条件：对偶稳定化（机制已加，阈值未标定）

`A_y` 是 `Ey` 的分母，`A_y → 0` 时 `1/A_y` 放大。本轮新增
`algo.ect_conformal_E_Astab`（默认 `0.1`，单位 `dx*dz`）：把 `0 < A_y < A_stab` 抬到 `A_stab`，
`A_y == 0`（fully covered）保持 0，掩膜因此仍冻结它。

扫描结果（§3.4）：`A_stab = 0.001/0.1/0.5/2/10` 对应的 PEC 内 `max|Ey|` 是
`7.1e6 / 6.9e6 / 2.4e6 / 1.3e6 / 1.8e5`，而环带场在 `A_stab = 2` 时已被抬高 58%。

**结论**：只抬分母的"半侧稳定化"不足以支撑"放开 cut 节点"，`A_stab ≈ 10` 才压得住热斑，
但那等于放弃共形。完整的对偶稳定化（分子/分母同时限制的 BCK 式，或 Dey–Mittra 阈值丢弃）
仍是必需项，且**必须排在 level-set 之前**。

### 5.1 必做，且唯一能到二阶：方案 C（level-set 精确对偶长度）

**做法**：初始化时（一次性、CPU、不进每步内核），对每条格心线用 level set `φ(x,z)` 求
`φ = 0` 的交点，积分开放段的长度：

```
Lx(i,j+½) = ∫_{x_i-h/2}^{x_i+h/2} [φ(x, z_{j+½}) <= 0] dx
Lz(i+½,j) = ∫_{z_j-h/2}^{z_j+h/2} [φ(x_{i+½}, z) <= 0] dz
```

实现要点：
- **符号约定**：本项目 `eb_implicit_function` **正值为固体**，所以"开放"是 `φ <= 0`
  （`C_SIDE_DESIGN2.md` §1.5 写的 `[φ>0]` 是反的，`C_SIDE_RESEARCH2.md` §2.3 已指出）；
- 采样 8–16 点 + 线性插值求交点，对 640² 也是"秒级/层"；
- 规则域上必须给出**精确** `dx`/`dz`（否则 L2a 退化不成立），用"全 `φ<0` 时直接返回 `h`"保证；
- 目标：`Lx/Lz` 的 RMS 阶 ≥ 1.8（当前 1.4）。

**预期**：近场阶数从 1.06 提到 1.5–1.8（受 E4 界面场一阶的限制，可能到不了 2.0）。

### 5.2 不要做：方案 A（面分数四面平均）

§3.2 已实测：RMS 比方案 B 大 15%，阶数一样。**原计划 F4 应作废**，
`C_SIDE_FIX_PLAN.md` 的 F4 改为"直接做方案 C"。

### 5.3 测量侧（与物理侧并行，成本低）

1. **RCS 减数值入射**：用同分辨率、同源、无散射体的真空跑，得到 `A_vac`，
   `Asc = A_al − A_vac·exp(i·phase)`（**乘同一个全局相位因子**，否则 RCS 会整体旋转）；
2. **把真空残差作为误差地板并列报告**：报告 `L2` 与 `floor` 两列，不宣称"物理阶数"；
3. **至少 4 档**（40/80/160/320）：三点拟合的局部阶数波动可达 ±0.2；
4. 若地板随 `dx` 只按 1 阶下降（色散是二阶，但固定拟合窗会引入一阶项），需要固定"物理窗"
   或用 `k_num` 做相位校正。

### 5.4 判据位置（可选，若 5.1 后仍不到 1.7）

Meep 文档明确"界面上的场至多一阶"。若 level-set 后近场仍是 1.5，应：
- 把近场判据移到 `3R–5R`（远离界面），或
- 以 RCS（远场积分量，对边界层误差有角度平均）为主判据。

### 5.5 需要单独验证的（E7）：B/E 几何同源

若 5.1 之后阶数仍不升，下一步是**把 B 侧的 `face_areas`/`edge_lengths` 也用同一套
level-set 积分重算**，使两侧严格同源。工作量约 +1 天，但这是"离散 Hodge star 成对"的严格条件。

## 6. 修正后的预期与验收

| 步 | 改动 | 验收判据 | 预期 |
|---|---|---|---|
| 1 | 方案 C（level-set 对偶长度） | 纯几何 RMS 阶 ≥ 1.8；规则域 `max\|L−h\| = 0` | 2 阶几何 |
| 2 | 米氏 4 档 + 真空地板 | `L2` 与 `floor` 两列；扣地板后阶数 ≥ 1.5 | 近场 1.5–1.8 |
| 3 | RCS 减数值入射 | RCS 阶数在 4 档上单调，且不再随相位抖动 | 1.8–2.0 |
| 4 | （若仍不足）B 侧同源化 | 两侧几何来自同一 level-set 积分 | 可能到 2.0 |

**诚实的预期管理**：即使做完 1–3，近场也可能停在 1.5–1.7，因为"界面上的场一阶"是
共形 FDTD 的公认限制（Meep 文档），不是本项目的实现缺陷。届时应以 RCS 与远场量作为
二阶验收对象，而不是近场逐点场。

## 8. 一句话

**阶数停在 1.0–1.3，是因为 `Lx`/`Lz` 用"相邻 cell 分数平均"估格心线长度（1.4 阶，换面分数也一样），
再叠加 15% 的真空测量地板和 RCS 减解析入射的伪影；`A_y`（2.4 阶）与掩膜都不是瓶颈。
唯一有效的修正是 level-set 精确求交；方案 A 已实测无收益，应从计划里删掉。**
