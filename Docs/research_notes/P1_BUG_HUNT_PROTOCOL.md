# P1 找 bug 测试流程（全面覆盖）

<!-- SPDX-License-Identifier: BSD-3-Clause -->


> 目标：在 P1（张量 ε、按分量 χ⁻¹ 行、τ 变换、bulk/对角分支、界面 f/n̂）
> 中找出**局部 3×3 运算与索引映射**的 bug。大算例的 R/T 只能看到"差几个 %"，
> 本流程用**单元级交叉核对 + 内核级合成输入 + 物理不变量**来定位。
> 原则：每个测试都能自动判 PASS/FAIL，失败时能唯一指向一个嫌疑。

---

## 0. 测试分级

| 级 | 内容 | 依赖场？ | 定位能力 |
|---|---|---|---|
| **L0** | 数学单元：τ/τ⁻¹、χ⁻¹ 三分支、行列/对称/旋转/端点 | 否 | 直接指向公式/索引 |
| **L1** | 内核：合成 D → E 更新 | 是（无传播） | 指向行乘、D 的 stagger/index、α/β |
| **L2** | 物理：双各向异性界面、能量、互易、f/φ 对偶、n 符号 | 是 | 指向界面流水线 |
| **L3** | 代码审计：grep + 逐行 | — | 兜底 |

---

## 1. L0 数学单元（15 项）

统一用 Python 参考实现（`p1_tensor_reference.py`）与 C++ 测试入口
（`p1_tensor_test`，读 CSV、调 `chi_inv_anisotropic`、写 CSV）对照。

| ID | 测试 | 做法 | 期望 | 失败指向 |
|---|---|---|---|---|
| L0.1 | τ 往返 | 1e4 随机 SPD ε：`tau_inv(tau(e))` | ≤1e-14 | τ 或 τ⁻¹ 公式 |
| L0.2 | τ⁻¹ 往返 | 随机合法 τ：`tau(tau_inv(T))` | ≤1e-14 | 同上 |
| L0.3 | 各向同性退化 | `chi_inv_isotropic` vs `P⟨ε⁻¹⟩+(I−P)⟨ε⟩⁻¹` | ≤1e-14 | 投影公式 |
| L0.4 | 单材料恒等 | `chi_inv_anisotropic(e,e,f,n)` vs `e⁻¹` | ≤1e-14 | 旋转/平均/求逆 |
| **L0.5** | **双各向异性** | e1、e2 都各向异性、随机 n、随机 f，逐元素比 | ≤1e-13 | **τ 是否对两个材料都做** |
| L0.6 | f 端点 | f=0 → ε2⁻¹；f=1 → ε1⁻¹ | 精确 | f 的加权/次序 |
| L0.7 | n 反向 | n→−n（不换材料） | 同一 χ⁻¹ | 法向符号依赖 |
| L0.8 | 切向基旋转 | 绕 n 转切向基 | 同一 χ⁻¹ | frame 构造 |
| L0.9 | 整体旋转协变 | Q e1 Qᵀ、Q e2 Qᵀ、Q n → Q χ⁻¹ Qᵀ | ≤1e-13 | 旋转/转回 |
| L0.10 | SPD | 所有用例 χ⁻¹ 对称正定 | 是 | 求逆/公式 |
| L0.11 | 2D vs 3D | n=(nx,0,nz) 的 2D 特例 vs 通用 frame | ≤1e-14 | 2D 特例 |
| L0.12 | 对角/ bulk 分支 | `chi=diag(1/ε)`；`chi=ε⁻¹` | ≤1e-14 | 分支填充 |
| L0.13 | 对称性 | χ⁻¹ 对称（ε 对称时） | ≤1e-14 | τ⁻¹ 的非对角 |
| L0.14 | 极端对比 | ε 比 1e6，闭式逆 vs numpy | 相对误差记录 | 病态处理 |
| L0.15 | 非 SPD | 传非正定 ε → 应 abort | abort | 断言路径 |

**覆盖组合**（L0.5 内至少 200 例）：
- 材料：各向同性/各向异性 × (e1,e2) = (I,I)、(A,I)、(I,A)、(A,B)；
- 法向：随机单位矢量（含 2D n_y=0）；
- f：0、0.25、0.5、0.75、1；
- 张量：随机 SPD、旋转对角、极端对比。

## 2. L1 内核单元（6 项）

在 1–2 个 cell 的网格上，直接设 D、χ⁻¹，跑**一次** E 更新（α=1、β0=dt、无 J）。

| ID | 测试 | 做法 | 期望 | 失败指向 |
|---|---|---|---|---|
| L1.1 | 行乘 | 已知 χ⁻¹、D=(Dx,Dy,Dz)，比 E 增量 | `β0·χ⁻¹·D` | 行乘公式 |
| L1.2 | 行/列映射 | D=(1,0,0)、(0,1,0)、(0,0,1) 三次，看 E_c 取到哪一列 | 第 d 列 | 列索引（c/d 反） |
| L1.3 | **stagger** | 给 Dy 一个 z 剖面、Dx=Dz=0，看 Ex 位置读到哪个 index 的 Dy | 与 Meep 同 index 约定 | collocated 偏格 |
| L1.4 | 对角分支 | 均匀 ε，三分量分别对 `1/ε` | 精确 | comp 填充（已修过 comp 0） |
| L1.5 | bulk 分支 | 均匀旋转张量，比 `ε⁻¹·D` | ≤1e-14 | bulk 行 |
| L1.6 | σ/α | 无 curl、σ>0：E(t) 应与指数/BE 解析一致 | ≤1% | α/β0/1+s |

## 3. L2 物理不变量（8 项）

| ID | 测试 | 做法 | 期望 | 失败指向 |
|---|---|---|---|---|
| **L2.1** | 双各向异性界面（法向） | e1、e2 都旋转张量，z 法向；横向模由 Schur 补给 R/T + **偏振转换** | R/T ≤2%（32 ppw）；转换比对上解析 | τ 双材料、界面 |
| L2.2 | P1-d 近场相位 | 旋转张量界面，比透射波相位（不只 R/T） | 相位 ≤2° | 旋转/求逆 |
| L2.3 | 能量守恒 | 均匀各向异性、无损波包：`E·ε·E+B·μ⁻¹·B` | 漂移 O(h²) | 非 Hermitian 索引 |
| L2.4 | 互易 | 交换 ε1↔ε2 + 反向入射，T 应相同 | ≤1% | 行列转置/次序 |
| **L2.5** | f/φ 对偶 | φ→−φ 且 ε1↔ε2（同一结构两种描述） | 结果逐位/≤1e-13 | f 计的是哪个材料 |
| L2.6 | n 符号 | 只翻 ∇φ（n→−n），不换材料 | 结果相同 | n 依赖 |
| L2.7 | 斜入射+各向异性（可选） | kx 守恒 + 偏振转换 | kx 0；转换比对上解析 | 界面/collocated |
| L2.8 | 曲面（可选） | 圆柱双各向异性 vs Meep | ≤2% | 曲面 f/n̂ |

## 4. L3 代码审计（grep + 逐行）

| 检查 | grep/位置 | 期望 |
|---|---|---|
| 分量索引 | 内核 `eix/eiy/eiz(i,j,k,0/1/2)` | 与行 c、列 d 一致 |
| D 的 stagger | `D_y`/`D_z` 在 E_c 位置的 index | 与 Meep `chi1inv[c][d]` 同 index |
| f/φ 符号 | `InitSubpixelRows` 里 f 的定义与 `epsilon`/`epsilon2` 次序 | 材料 1 一致 |
| 双各向异性 | `chi_inv_anisotropic(e1,e2)` | 两个都旋转+τ |
| 界面帧求逆 | `χ'=(ε̄')⁻¹`、`χ=R χ' Rᵀ` | 符号/顺序 |
| 2D 特例 | `e3=n×e2`、`n=(nx,0,nz)` | 右手性；n 反向不变 |
| μ 行 | `m_mu_inv_*` | 未实现（P2 前静默忽略） |
| `plo` 索引 | `plo[AMREX_SPACEDIM-1]` | 2D 用 index 1 |

## 5. 仪器化（要写的代码）

1. **C++ 测试入口** `p1_tensor_test`（不进生产）：
   - 读 `p1_cases.csv`（e1 6 分量、e2 6 分量、n 3、f）；
   - 调 `chi_inv_anisotropic`（和 iso/bulk/diag），写 `p1_cpp.csv`（χ 9 分量）；
   - 用 `SubpixelTensor.H`，不依赖 WarpX 运行时。
2. **Python 参考** `p1_tensor_reference.py`：
   - 生成 `p1_cases.csv`（固定种子、覆盖 §1 的组合）；
   - 独立算 χ，写 `p1_expected.csv`；
   - `--compare p1_cpp.csv` 输出逐例最大相对误差与 FAIL 列表。
3. **运行期 dump**（可选）：`InitSubpixelRows` 里对指定 cell（env `P1_DUMP_CELLS`）
   打印 f、n、χ 9 个值，便于和 Python 对**真实算例**的 cell。
4. **L1 内核测试**：小网格、固定 D、一次更新；可做成独立 C++ 测试或 Python 驱动输入。

## 7. 执行顺序与判定树

```
L0（15 项，分钟级）
 ├─ L0.5 失败 → 看 L0.1–L0.4 定位：τ / 旋转 / 平均 / 求逆
 ├─ L0.7 失败 → 法向符号
 ├─ L0.9 失败 → 旋转协变
 └─ 全过 → L1
L1
 ├─ L1.2 失败 → 行/列映射
 ├─ L1.3 失败 → collocated stagger
 └─ 全过 → L2
L2
 ├─ L2.1 失败 → 双各向异性界面（τ 双材料/求逆）
 ├─ L2.5 失败 → f/φ 材料次序
 ├─ L2.3 失败 → 非 Hermitian 索引
 └─ 全过 → P1 的 3×3 运算可认为正确
L3 与 L0 并行（审计兜底）
```
