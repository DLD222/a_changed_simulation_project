# A：TM 基线验证（PEC 反射 r=−1）

<!-- SPDX-License-Identifier: BSD-3-Clause -->


> 算例目录：`benchmarks/cases/c02_0_pec/`
> 代码：`~/WarpX_fluid`（2D 构建 `warpx.2d.MPI.OMP.DP.PDP.EB`）
> 日期：2026-10-31

## 1. 目的

在 2D XZ + ECT 下建立 **PEC cut-cell 几何自检基线**。由于上游 2D ECT 只支持 TM 模
（见 `ROOTCAUSE_ECT_2D.md`），本基线的偏振取 **TM（Ex 入平面，By 出平面）**。

## 2. 设置

| 项 | 值 |
|---|---|
| 维度/求解器 | 2D XZ，`algo.maxwell_solver = ect` |
| 域 | [−15, 15]² m，PML 四边 |
| EB | 平面 `z = 0`（α = π/2，法向 +z，PEC 在 z>0） |
| 源 | 场初始化：`Ex = E0·exp(−((z−zc)/w)²)`，`By = Ex/c`，`E0=1e6 V/m`，`zc=−8`，`w=1.5` |
| 探针 | `(x,z) = (0,−5)` |
| 分辨率 | n = 384 / 768 / 1152（dx = 30/n m） |
| CFL | 0.4；`stop_time = 80 ns` |

入射脉冲中心在 z=−8，探针在 z=−5（3 m），平面在 z=0（再 5 m）。
解析预测：入射峰 t = 3/c ≈ 10.0 ns；反射峰 t = 10.0 + 2×5/c ≈ 43.3 ns；PEC 正入射 r = −1。

## 3. 结果

| n | dx (m) | 入射峰 | 反射峰 | **r** | 偏差 |
|---|---|---|---|---|---|
| 384 | 0.0781 | 10.024 ns, +1.0000e6 | 43.488 ns, −9.9933e5 | **−0.999295** | 0.071% |
| 768 | 0.0391 | 10.024 ns, +1.0000e6 | 43.414 ns, −9.9969e5 | **−0.999679** | 0.032% |
| 1152 | 0.0260 | 10.024 ns, +1.0000e6 | 43.439 ns, −9.9979e5 | **−0.999793** | 0.021% |

- 入射时刻 10.024 ns（解析 10.0 ns，误差 0.2%）。
- 反射时刻 43.4–43.5 ns（解析 43.3 ns，误差 <0.5%）。
- **r → −1 随分辨率收敛**（0.071% → 0.032% → 0.021%），一阶量级收敛。
- 反射脉冲符号为负（相位反转），符合 PEC 切向 E=0。

## 4. 复现

```bash
cd benchmarks/cases/c02_0_pec
sh run_tm_sweep.sh
```

脚本对 n ∈ {384,768,1152} 生成 `inputs_tm_<n>`（`amr.n_cell` 与 `max_step` 同步放大，确保 `stop_time`
主导、反射脉冲不被截断），运行后用 `analyze_tm.py` 提取入射/反射峰与 r。

> 注意：若只改分辨率不改 `max_step`，高分辨率下 dt 变小、800 步覆盖的物理时间不足以让反射脉冲到达探针
> （曾因此在 n=768/1152 误判为 r≈0）。

> **复算（2026-10-31 晚，ECT 初始化时序修复后）**：n=384 单点复算得
> 入射 10.024 ns / `Ex=+1.000021e6`，反射 43.488 ns / `Ex=−9.993821e5`，
> **`r = −0.999361`**（修复前为 −0.999295）。时刻不变、|r| 略优，说明该修复对 TM
> 只有二阶影响。见 `ECT_2D_TE_REPORT.md` §14.4。

## 5. 结论与边界

1. **TM 偏振下 ECT 的 PEC 反射正确**：r 收敛到 −1（<0.1%），时刻与解析一致。可作为 C2-0 的合格基线。
2. **仅覆盖 TM**：TE（Ey/Bx/Bz）在 2D XZ ECT 下不支持（缺 `Rhox`/`Rhoz`），需转 3D 或补 2D 分支（即 B 项）。
3. **基底（instrument floor）**：ECT 必须开 EB，无法直接做"无 EB 真空对照"；后续可用"PEC 平面远离探针"
   或 3D 真空对照补齐本底测量。
4. 该基线是后续 **B（补 2D TE）** 与 **C（E 场共形 Ampere + 对偶几何）** 的对照起点。
