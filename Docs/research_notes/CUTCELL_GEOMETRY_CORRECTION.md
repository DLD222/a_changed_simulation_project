## 0. 结论先行

1. **单胞几何**：AMReX 在 cell 内用"边界与 cell 边的交点连线"（chord）代替真边界；
   chord 的斜率是两端交点的割线斜率，**不是** ∇φ；chord 与真曲线的偏差是弓高 `O(h²)`。
2. **"|∂xφ|→0 放大到 O(h)"不成立**：交点不在切点；chord 与真曲线在交点处**相交**（误差在端点为零）；
   对偶线离切点最近也有 `ε=h/2`，交点处 `|∂xφ|≈√(h/R)`，不趋零。
3. **测量勘误**：我的旧脚本把 z 向对偶线拿去和 x 向的精确值比较（不同几何量），RMS 虚高、阶数报错。
   修正后：**volfrac（方案 B）≈0.14h、一阶；scheme 4（节点 φ 双线性）≈0.005–0.03h、二阶**（1.97/1.59/2.15）。
4. **结论**：C 侧 `Lx` 的几何**已经是二阶**；米氏近场停在 ~1.0 阶**不能**再归因于 `Lx` 构造，
   一阶来源应到掩膜/BCK/界面场/测量地板里找。方案 B 对**平面**精确、对**曲面**一阶，是简单稳健的
   回退项，但不是冲二阶的路径。parser 的价值是"去掉 chord/线性化的 O(h²) 形状误差"，
   对 `Lx` 而言**不是二阶的必要条件**（scheme 4 已二阶），是"更小常数 + 严格同源"的可选项。

## 1. 单胞几何（正确画面）

### 1.1 AMReX 如何把边界变成"线性方程"

一个 cut cell 有 4 个节点 φ 值。AMReX（`AMReX_EB2_2D_C`）的做法：

1. 检查 cell 的 4 条边，凡两端 φ 异号的边，用**线性插值**求出交点（每条边一个交点）；
2. 部分覆盖的 cell 恰好有 2 个交点，**用连接这两点的直线（chord）** 作为该 cell 内的边界；
3. 由这条 chord 与 cell 边的几何关系，得到 `volfrac`（面积分数）、`face_areas`、`edge_lengths`。

所以：

- cell 内的"线性方程"是 **过两个交点的割线**；
- 它的斜率 = 两交点连线的斜率（= 割线方向），**不是** 交点处的 ∇φ；
- chord 与真曲线的最大偏差是弓高（sagitta），对半径 R 的圆弧约 `sag = (L/2)²/(2R)`，
  `L ≤ √2 h` ⇒ **`O(h²)`**；
- chord 与真曲线在**两个交点处重合**（误差在端点为零，中间最大）。

### 1.2 两个几何量的阶不同

| 量 | 来源 | 误差 |
|---|---|---|
| **1D 交点/边长**（edge_lengths、对偶线交点） | 沿一条**直线**求 φ 的零点（线性插值） | `O(h²)`（φ 沿直线光滑） |
| **2D 面积分数**（volfrac、face_areas[1]） | chord 与 cell 围成的面积 | chord 与圆弧之间那块面积 `O(h³)`（弓高 O(h²) × 宽 O(h)）⇒ **面积分数误差 `O(h³)/h² = O(h)`** |

这解释了一个容易混淆的事实：**同一套 chord，1D 量可以二阶、2D 面积分数只能一阶**。
对曲面边界，"面积分数"本身是一阶量，这与用哪种公式无关（只要用 chord 算面积）。

### 1.3 为什么"|∂xφ|→0 放大"不成立

- 对偶线在 `z = z_{j+1/2}`，与切点 `z=±R` 最近的距离是 `h/2`（离散高度不会落在切点）；
- 该线上交点 `x = ±√(R²−z₀²) = ±√(2Rε)`，`ε ≥ h/2` ⇒ `|x| ≥ √(Rh)`，
  交点处 `|∂xφ| = |x|/R ≥ √(h/R)`——随 h 减小，但只到 `√h`，**不是 0**；
- 即便交点靠近切点，chord 与真曲线在交点处**相交**，误差在端点为零，不会出现"除以 ∂xφ"的发散；
- 因此交点位移、进而长度误差保持 `O(h²)`——与 §3 的测量一致。

## 3. 测量勘误：bug、修法、结果

### 3.1 bug

旧脚本（`/tmp/geomC.py`）对每个 cut 格同时累加两项：

```python
e.append((len_x(phi,i,j,h)-ex)**2)   # x 向对偶线
e.append((len_z(phi,i,j,h)-ex)**2)   # z 向对偶线 —— 却用了 x 向的 ex！
```

其中 `ex = line_exact(z0=z_j+h/2, a=x_i−h/2, b=x_i+h/2)` 是 **x 向**线的精确值。
z 向对偶线在 `x = x_i+h/2`，其精确值是另一个量（`(z0=x_i+h/2, a,b=z_j±h/2)` 的开放长度）。
把 z 向线与 x 向的精确值比较 ⇒ **错误量纲对齐**，RMS 虚高约 3–5 倍，阶数被带成"1.0/0.9"。

### 3.2 修法

- 每条对偶线用**它自己的**精确值：x 线用 `line_exact(z0, x_i−h/2, x_i+h/2)`；
  z 线用 `line_exact(x0, z_j−h/2, z_j+h/2)`（`line_exact` 对圆对称，形式相同）；
- 分别统计 `Lx`、`Lz` 的 RMS/阶（不再混在一起）；
- 只统计 `1e-12 < L < h−1e-12` 的 cut 线（规则/全开放/全覆盖段精确返回 h/0，无误差）。

### 3.3 修正后的结果

解析圆，`R=1`，对偶线在 cell 中心高度；两条对偶线（x 向、z 向）分别测：

| n | h | **volfrac（方案 B）** RMS | 阶 | **scheme 4（节点 φ 双线性）** RMS | 阶 |
|---|---|---|---|---|---|
| 40 | 0.200 | 2.85e-2（0.143h） | — | 5.92e-3（0.030h） | — |
| 80 | 0.100 | 1.41e-2（0.141h） | 1.01 | 1.51e-3（0.015h） | 1.97 |
| 160 | 0.050 | 8.35e-3（0.167h） | 0.76 | 5.01e-4（0.010h） | 1.59 |
| 320 | 0.025 | 3.44e-3（0.137h） | 1.28 | 1.13e-4（0.005h） | 2.15 |

（z 向对偶线数值与 x 向相同，圆对称。）

结论：
- **volfrac：一阶**（~0.14h），与"2D 投影成 1D"的维度错配一致；
- **scheme 4：二阶**（~0.005–0.03h），比 volfrac 小一个数量级；
- 之前"scheme 4 一阶"的结论作废。

## 4. 术语澄清

### 4.1 volfrac（方案 B）是什么

`v(i,j)` = cell 的**面积分数**（AMReX 由 chord 算出的开放面积 / h²）。方案 B 用它反推对偶长度：

```
Lx(i,j) = ½ h [ v(i−1,j) + v(i,j) ]      Lz(i,j) = ½ h [ v(i,j−1) + v(i,j) ]
```

- 这是把 **2D 量**（面积分数）当 **1D 量**（线长）用；
- 对**平面**边界精确（面积分数沿 x 线性，块平均等于中点值）；
- 对**曲面**，面积分数本身是一阶量（§1.2），再投影一次 ⇒ 一阶（实测 0.14h）。

### 4.2 scheme 4（节点 φ 双线性求交）是什么、为什么二阶

代码（`EmbeddedBoundaryInit.cpp` 的 `open_len_x_from_ls`）：

1. 取 `eb_fact.getLevelSet()`（**节点** φ，每节点一个值）；
2. 对偶线在 `z=z_{j+1/2}`：对线上每个采样点 x，先在 **x 方向**线性插值（两个节点之间），
   再在 **z 方向**取 `½(φ_j+φ_{j+1})`（等价于双线性插值）；
3. 找 `φ` 的符号变化，两点间线性插值求交点；
4. 累加开放段的长度（`nseg=8` 段），规则区直接返回精确 `h`。

**为什么二阶**：双线性插值对光滑 φ 的点误差是 `O(h²)`；零等值面的交点位移随之 `O(h²)`
（§1.3 已说明没有额外放大）；长度 = 交点位置之差 ⇒ `O(h²)`。实测 1.97/1.59/2.15。

### 4.3 parser 是什么

`warpx.eb_implicit_function` 那段**解析表达式**（如 `R − sqrt(x^2+z^2)`）。
parser 可以在**任意点**求 φ，沿对偶线直接求根（二分/牛顿）⇒ 只剩求根容差，没有 chord/双线性的
`O(h²)` 形状误差。它是"精确几何"的参照，但对 `Lx` 来说**二阶不是必须**（scheme 4 已二阶），
其价值在于更小的常数与"与 B 侧严格同源"（若 B 侧也改用 parser 积分）。

## 5. 方案 B 到底有没有价值

**有，但不在"曲面二阶"这条路上。** 具体：

| 场景 | 方案 B 的表现 |
|---|---|
| 平面/轴对齐或 45° 平面边界 | **精确**（面积分数线性），简单、便宜、非常稳健 |
| 曲面边界（圆、球、任意曲线） | 一阶（0.14h），比 scheme 4 差一个量级 |
| 需要二阶远场/RCS | 不是合适选择（除非配合 subpixel 等效系数） |
| 作为回退/鲁棒性选项 | 有价值：不依赖 level set 的求交，不会出现局部尖角、对极端几何更稳 |

所以方案 B 的定位应是：**平面几何/回退路径**；冲二阶时 C 侧用 scheme 4（或 parser）。

## 6. 怎么实现二阶

按"几何 → 系数 → 界面场 → 测量"四层看：

1. **C 侧对偶长度（Lx/Lz）**：scheme 4 已二阶（本次实测）。若要更小常数/严格同源，用 parser
   沿线求根；但这不是二阶的必要条件。
2. **B 侧几何量**：
   - `edge_lengths`（1D，沿 cell 边求交点）本质是二阶；
   - `face_areas[1]`（cell 面积分数）是**一阶**（§1.2 的弦-弧面积 ⇒ O(h) 分数误差）；
   - 若 B 侧也用 volfrac 一阶量，则 E/B 两侧阶不同源，整体仍受 B 侧限制；
   - 要二阶，B 侧面积也要用**等效/子像素系数**（M2b 的 Kottke 张量），而不是精确面积分数本身。
3. **界面场**：即使几何二阶，界面上的场本身是**一阶**（Meep 文档 limitation 4）；近场 L2 会因此封顶，
   验收应转向 RCS/远场量（或 3R–5R 的环带）。
4. **测量**：真空地板 ~14%（与分辨率无关，源/PML 伪影）——先修测量（数值入射/RCS、加宽脉冲），
   否则几何再准也测不出阶数。

## 8. 结论与建议

1. 单胞几何：chord（交点连线），偏差 O(h²)；面积分数 O(h)，交点点位 O(h²)。
2. 测量（修正 bug 后）：**volfrac 一阶、scheme 4 二阶**；C 侧 `Lx` 不是米氏一阶的来源。
3. 方案 B：平面精确、曲面一阶，保留为回退/平面选项；不用于曲面二阶目标。
4. 二阶路径：C 侧用 scheme 4（已有）；B 侧面积用 subpixel 等效系数；界面场一阶是硬上限，
   验收转向远场/RCS；测量地板先修。
5. 建议把 §7 的勘误并入 `CUTCELL_GEOMETRY_PRINCIPLE.md`（是否并入由项目决定）。
