## 0. 第一版错在哪（批判清单）

分两类：**会直接导致 C-1 失败的公式错误**（P0），和**会导致返工的设计缺口**（P1/P2）。

### 0.1 P0：照第一版实现，规则域退化必然不成立

| # | 第一版写法 | 正确写法 | 后果 |
|---|---|---|---|
| D-1 | `Ex`/`Ez` 的 `A_dual = 1`（每单位 y），切割记在"对偶边长" | `Ex` 的分母是 `Lz`（沿 z 的开放长度），`Ez` 的分母是 `Lx`；分子里的 `By` 权重为 1 | 退化后差 `dz`/`dx`，C-1 不可能为 0 |
| D-2 | `Ey` 内核把 `Bx(i,j)` 与 `Bx(i−1,j)` 平均再 `/2` | 单个边中点值乘该边的开放长度：`Bx(i,j+½)·Lx(i,j+½)`，**没有相邻平均** | 规则域等价于"先做一次 x 方向平滑再差分"，与 Yee 不同，C-1 不可能为 0 |
| D-3 | §3.3 退化检查写 "`A_dual=1, Lz=dz → /dz`" | 代入 `B·L/A` 得 `B·dz`，不是 `/dz`；自相矛盾 | 会误导实现者去"补一个 dz" |
| D-4 | 只分配 `dual_face_area`（1 个 (1,1) 数组） | 需要三套：`A_y`（节点）、`Lx`（`(i,j+½)`）、`Lz`（`(i+½,j)`） | `Ex`/`Ez` 无分母可读 |

## 1. 正确的 2D 对偶几何

### 1.1 从源码钉死交错（不靠记忆）

`EvolveE.cpp:167-199`（2D 模板，`DownwardDy ≡ 0`）：

```
Ex(i+½,j) += c²dt·( −∂z By )
Ey(i,j)   += c²dt·( −∂x Bz + ∂z Bx )
Ez(i,j+½) += c²dt·( +∂x By )
```

`B` 侧（`EvolveBCartesianECT`）已用且已验证的对应关系：

| 量 | 位置 | 说话方式 | 对应的 AMReX 量 |
|---|---|---|---|
| `Bx(i,j+½)` | `(x_i, z_{j+½})` | cell 的 x-lo 面中心 | `face_areas[0](i,j)` ← `getAreaFrac()[0]` |
| `By(i+½,j+½)` | `(x_{i+½}, z_{j+½})` | cell 中心 | `face_areas[1](i,j)` ← `getVolFrac()` |
| `Bz(i+½,j)` | `(x_{i+½}, z_j)` | cell 的 z-lo 面中心 | `face_areas[2](i,j)` ← `getAreaFrac()[1]` |

> 源码依据：`EmbeddedBoundaryInit.cpp:602-660`（XZ 分支：`face_areas[0/2]` 由 `getAreaFrac()` 填，
> `face_areas[1]` 由 `getVolFrac()` 填）；`ScaleAreas` 再把无量纲分数乘成物理长度。

**由此确定 C 侧三个量的"住址"**（本文的核心结论）：

| 量 | 位置 | 与谁同位 | `IntVect` | 规则值 |
|---|---|---|---|---|
| `A_y` | 节点 `(x_i, z_j)` | 与 `Ey` 同位 | `(1,1,0)` | `dx·dz` |
| `Lx` | `(x_i, z_{j+½})` | **与 `Bx` 同位** | `(1,0,0)` | `dx` |
| `Lz` | `(x_{i+½}, z_j)` | **与 `Bz` 同位** | `(0,1,0)` | `dz` |

"与 B 分量同位"这一点极大降低了索引风险：**`Lx` 就是 `Bx` 所在那条格心线上的开放长度**，
`Lz` 就是 `Bz` 所在那条格心线上的开放长度。两者都是"垂直于 B 的分量方向"的开放长度。

### 1.2 三条内核公式（正确版）

```
Ex(i+½,j) += −c² dt · [ By(i+½,j+½) − By(i+½,j−½) ] / Lz(i+½,j)

Ez(i,j+½) += +c² dt · [ By(i+½,j+½) − By(i−½,j+½) ] / Lx(i,j+½)

Ey(i,j)   += +c² dt · [ Bx(i,j+½)·Lx(i,j+½) − Bx(i,j−½)·Lx(i,j−½)
                      − Bz(i+½,j)·Lz(i+½,j) + Bz(i−½,j)·Lz(i−½,j) ] / A_y(i,j)
```

**退化验证**（`Lx=dx`、`Lz=dz`、`A_y=dx·dz`）：

| 分量 | 代入 | 结果 | 源码模板 | 一致 |
|---|---|---|---|---|
| `Ex` | `−[ΔBy]/dz` | `−∂z By` | `:167-175` | 是 |
| `Ez` | `+[ΔBy]/dx` | `+∂x By` | `:191-199` | 是 |
| `Ey` | `[ΔBx·dx − ΔBz·dz]/(dx dz)` | `ΔBx/dz − ΔBz/dx` | `:180-188` | 是 |

三条都可**逐位**退化（只要 `L`/`A` 在规则域上是精确常数，无浮点舍入差异）。

### 1.3 为什么 `Ex` 的分母是长度而不是 1（一版错在这里）

3D 的 Ampere 对偶面（围绕 x 边）法向 `x`，面积 `dy·dz`。2D 的 `∂y = 0` 意味着所有量按
单位 `y` 归一，但**面积仍是 `Lz × 1`，不是 `1`**。一版把"单位 y"当成了面积本身，
等价于把 `dz` 吃掉，于是 `Ex` 的更新被放大 `1/dz`。

同理 `Ey` 的对偶面法向 `y`，面积 `dx·dz`（节点处 4 个 ¼ 胞）；`Ez` 的对偶面法向 `z`，面积 `Lx × 1`。

### 1.4 `A_y` 的四象限（唯一可 1/4 的量）

```
A_y(i,j) = ¼ dx dz [ v(i−1,j−1) + v(i,j−1) + v(i−1,j) + v(i,j) ]
```

`v = volfrac`。**只有 `Ey`（节点量）是"四象限各 ¼"**；`Ex`/`Ez` 是边量，对偶面是线段，没有 ¼。
第一版把这个 ¼ 的表述推广到所有分量，是概念性错误。

### 1.5 `Lx`/`Lz` 怎么算（三种方案，按精度/成本排序）

`Lx(i,j+½)` = 格心线 `z = z_{j+½}` 上、`x ∈ [x_i − dx/2, x_i + dx/2]` 的开放长度。
它在 **cell (i,j) 的左半 + cell (i−1,j) 的右半** 之内，**不是任何一个主面**。

**方案 A（推荐默认，一阶）**：用相邻两个主面的开放度平均到中间

```
Lx(i,j+½) = ½ dx [ a_z(i,j) + a_z(i,j+1) ]      // a_z = getAreaFrac()[1]，cell 的 lo-z 面
Lz(i+½,j) = ½ dz [ a_x(i,j) + a_x(i+1,j) ]      // a_x = getAreaFrac()[0]，cell 的 lo-x 面
```

理由：`a_z(i,j)` 是 `z = z_j` 面上的开放长度，`a_z(i,j+1)` 是 `z = z_{j+1}` 面上的；
格心线正好在两者中间，取平均在**位置**上是二阶的（误差来自两面之间开放长度的一阶变化）。

**方案 B（备选，一阶）**：用 `volfrac` 的两个 cell 平均

```
Lx(i,j+½) = ½ dx [ v(i−1,j) + v(i,j) ]
Lz(i+½,j) = ½ dz [ v(i,j−1) + v(i,j) ]
```

两者在近水平/近竖直界面上各有优势，**必须用 45° 斜面同时算并对比解析值**，选误差小的那个。
初版设计只写"读 `area_frac`"，没有区分方案的适用面，这是 D-5 的实质。

**方案 C（最终精度，二阶）**：初始化时用 level set 求交

几何量只在 `InitializeEBGridData` 算**一次**，不进每步内核，所以完全可以用 CPU 做精确计算：

```
对格心线上的 N 个采样点（N = 8~16），取 φ(x,z)（EB level set），
开放长度 = Σ step · [φ > 0]，边界交点用线性插值细化
```

成本：每层 `O(n_cell × N)`，对 640² 也不到 1 秒。**这是把 C 侧从 1 阶推到 2 阶的关键一步，
建议 S1 先用 A，S9 收敛阶测试前换 C。**

> 索引陷阱：AMReX 的 `getAreaFrac()[idim]` 给的是 cell 的 **lo 侧** `idim` 面。
> 必须在 S1 用一个"只有左半开放"的单 cell 手算验证（lo 面 = 0.5、hi 面 = 1），
> 否则 A/B 两案的索引会整体偏移一格。**这一步不做，后面全部白费。**

## 2. 内核实现（含边界与符号）

### 2.1 开关

```
algo.ect_conformal_E = 0   (默认)
```

`WarpX.cpp` 解析 → `m_fdtd_algo==ECT && m_ect_conformal_E && (dims==2)` 才走新内核。

**三层退化保证**：
1. 开关关 → 旧路径（C-0，逐位）；
2. 开关开 + 规则域 → 常数几何时与 Yee 逐位（C-1a）；
3. 开关开 + 真实几何 + 规则域 → 仍逐位（C-1b）。

### 2.2 分派点

```cpp
// EvolveE.cpp:92 附近
} else if (m_fdtd_algo == MaxwellSolverAlgo::ECT) {
    if (m_ect_conformal_E && WARPX_DIM_XZ) {
        EvolveECartesianECT<EvolveE_ECT_Algo>(...);   // 新
    } else {
        EvolveECartesian<CartesianYeeAlgorithm>(...); // 现状
    }
}
```

### 2.3 内核要点

1. **不重算几何**：`A_y`、`Lx`、`Lz` 从 MultiFab 读，核心里禁止出现 `dx*dz`（否则退化不可验证）。
2. **covered 点**：
   - `A_y <= 0` → `Ey = 0`（写回，不只是跳过）；
   - `Lz <= 0` → `Ex = 0`；`Lx <= 0` → `Ez = 0`；
   - 判据用 `<= 0`（不是 `< 1e-16`），因为 AMReX 对 covered 给精确 0。
3. **`eb_update_E` 的新语义**：只在"covered"上生效（强制 0）；cut 但开放的点**不再冻结**。
   与现有 `MarkUpdateECellsECT` 的差异在此，需要同步改该函数（S6 之后单独一步）。
4. **PML 区**：新内核只作用于 `Efield` 的 non-PML 区。实现上沿用 `EvolveECartesian` 的 box 逻辑
   （PML 的 E 由 `EvolveEPML` 单独处理），另加**断言**：若 EB 与 PML 的 box 相交则 abort
   （当前算例 EB 都在内部，不会触发；这是防止将来静默错误）。
5. **`J` 项**：保持 `E += −dt·J/ε0` 的独立分支。若开关打开且 `J` 非零，**先 abort 并提示
   "C 侧尚未实现 J 的对偶积分"**，不要静默置零（D-8）。

### 2.4 内存与生命周期

```
分配（仅 ECT + 2D + 开关开）：
  dual_A_y  : MultiFab(1, IntVect(1,1,0), nGrow=1)
  dual_L_x  : MultiFab(1, IntVect(1,0,0), nGrow=1)
  dual_L_z  : MultiFab(1, IntVect(0,1,0), nGrow=1)
```

- 与 `face_areas` 同批分配（`WarpX.cpp` ECT 段）、同批 `FillBoundary`、同批进 checkpoint；
- `FillBoundary` 必须在 `ComputeDualGeometry` **之后**调用一次（节点量跨 box 需要邻居值）；
- `Fields.H` 的 ECT 字段列表加三项；否则重启后 `A_y` 全零 → 除零。

### 2.5 稳定化（诚实：这一条仍未闭合）

与 B 侧对称的位置是：`A_y`、`Lx`、`Lz` 都存在"小值"。但三者角色不同，不能一起抬：

| 量 | 角色 | 抬升的风险 |
|---|---|---|
| `A_y`（`Ey` 分母） | 小值 ⇒ `Ey` 增益 ⇒ 不稳定 | 抬升等价于"把节点对偶面积填平"，物理上可接受（BCK 思想） |
| `Lx`/`Lz`（`Ex`/`Ez` 分母） | 同上 | 同上，但影响 `Ex`/`Ez` 的 CFL |
| `Lx`/`Lz`（`Ey` 分子权重） | 通量守恒 | **抬升会破坏 `Ey` 的离散通量守恒** |

因为 `Lx` 同时是 `Ez` 的分母与 `Ey` 的分子，**不能简单抬**。可行路径（按优先级）：

1. **只抬 `A_y`**（`Ey` 分母）与 **`Lz`/`Lx` 作为 `Ex`/`Ez` 分母时**，且抬升只作用于分母的副本
   （即 `1/L` 用 `1/max(L, L_stab)`），分子仍用真实 `L`。这会引入 O(1) 的通量不一致，
   但避免了"分子分母同时改"的二阶误差；
2. 标定 `L_stab`、`A_stab`：在 `volfrac` 扫描（`1e-1 → 1e-6`）中找临界 `f`，反推系数；
3. 若仍不稳，退到 Dey–Mittra 阈值（`f < 1e-3` 的 cell 阶梯化），并记录精度损失。

`A_stab` 的闭式推导（BCK 的 "user-defined geometric precision"）**本设计不做**，
以数值标定代替 —— 这一点必须在文档与代码注释里写清楚，不要假装有理论依据。

## 5. 3D 推广（结构，不展开公式）

3D 的对应关系与 2D 同构，但每个 `E` 分量的对偶面是**四象限**（不再是线段）：

| 分量 | 对偶面 | 面积 | 分子权重 |
|---|---|---|---|
| `Ex` | `yz` 平面，围绕 x 边 | `¼ dy dz Σ`（4 个 cell 的 `a_x`） | `By`×`Lz`、`Bz`×`Ly` |
| `Ey` | `xz` 平面 | `¼ dx dz Σ` | `Bx`×`Lz`、`Bz`×`Lx` |
| `Ez` | `xy` 平面 | `¼ dx dy Σ` | `Bx`×`Ly`、`By`×`Lx` |

3D 的难点：`Lx`/`Ly`/`Lz` 各有 4 个位置（围绕边的 4 个 cell 的角），需要 4 套索引；
以及 `¼` 的象限归属容易错。**建议 2D 全部判据通过后再动 3D，且 3D 只做 `A` 的共形、
`L` 先用方案 A 的一阶近似。**

## 7. 未解决/需外部确认的问题（不隐藏）

1. **`A_stab`/`L_stab` 无闭式**：只有数值标定。若你要"有理论依据的稳定化"，需要单独做
   BCK 判据在 E 侧的推导（约 1 天纯理论工作）。
2. **`Lx`/`Lz` 的分子/分母双重角色**：这是本设计里唯一"可能需要引入额外自由度"的地方。
   如果 S9' 的 TM 长跑仍不守恒，说明分子侧也需要同一套稳定化 —— 那就必须引入"分子用真实值、
   分母用稳定值"的记账（等价于 B 侧的 `Venl`），复杂度上升约 30%。
3. **AMReX `getAreaFrac()` 的 lo/hi 语义**：本文按"lo 面"写，**必须由 S1a' 实测确认**。
   若实际是 hi 面，方案 A/B 的索引全部 `+1`。
4. **AMR**：本文只保证单层。多层需要 `C_SIDE_DESIGN.md` §6 的 per-level 初始化，
   且 `A_y`/`Lx`/`Lz` 在粗-细界面的插值需要新的判据（建议单独写 `C_SIDE_AMR.md`）。
5. **PIC 电流沉积**：不在本文范围（J=0）。加粒子后需要 cut cell 上的守恒沉积，见
   `C_SIDE_RESEARCH.md` §2.5。

## 8. 一页速查（实现时贴在手边）

```
位置（2D XZ）：
  Ey, A_y  : 节点 (i,j)            IntVect(1,1,0)
  Bx, Lx   : (i, j+½)              IntVect(1,0,0)
  Bz, Lz   : (i+½, j)              IntVect(0,1,0)
  By       : 格心 (i+½, j+½)

规则值：A_y = dx·dz, Lx = dx, Lz = dz

Ex(i+½,j) += −c²dt [ By(i+½,j+½) − By(i+½,j−½) ] / Lz(i+½,j)
Ez(i,j+½) += +c²dt [ By(i+½,j+½) − By(i−½,j+½) ] / Lx(i,j+½)
Ey(i,j)   += +c²dt [ Bx(i,j+½)Lx(i,j+½) − Bx(i,j−½)Lx(i,j−½)
                    −Bz(i+½,j)Lz(i+½,j) + Bz(i−½,j)Lz(i−½,j) ] / A_y(i,j)

A_y(i,j) = ¼ dx dz [ v(i−1,j−1)+v(i,j−1)+v(i−1,j)+v(i,j) ]
Lx(i,j+½) = ½ dx [ a_z(i,j) + a_z(i,j+1) ]      ← 方案 A
Lz(i+½,j) = ½ dz [ a_x(i,j) + a_x(i+1,j) ]      ← 方案 A

禁止：相邻 B 取平均；核心内出现 dx*dz；covered 点只跳过不写 0；开关关时走新路径。
必做：S1a' 先钉死 lo/hi；S2' 用常数几何跑出 max|d|=0 再碰真实几何。
```
