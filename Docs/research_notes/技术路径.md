# 技术路径：介质（张量 ε/μ/σ）场求解器 —— Yee + subpixel + 矩阵指数

<!-- SPDX-License-Identifier: BSD-3-Clause -->


> 日期：2026-10-31 · 状态：设计稿（基于两轮问答 + 文献/源码调研）
> 范围：2D（XZ）与 3D 一起设计；ε、μ、σ 为**静态**（只随空间变）的 3×3 张量；
> **纯材料**（无粒子，自由电流只有 σE）；**显式 Yee**；界面用 **subpixel**；
> PEC 用 **EB mask**，金属在介质中走 subpixel；σ 用**矩阵指数积分**；`ρ_f` 为**节点**独立场；
> **不做投影**，靠电荷守恒更新维持 Gauss；新增张量材料选项（`macroscopic.tensor`），只增不减；
> 不修改 ECT/C 侧（cut-cell 路径）。

## 1. 方程组与张量本构

```
① ∂_tD = ∇×H − σ·E                    （Ampere–Maxwell，自由电流只有 σE）
② ∂_tB = −∇×E                         （Faraday）
③ ∂_tρ_f + ∇·(σ·E) = 0                （自由电荷连续性）
约束：∇·D = ρ_f,  ∇·B = 0
本构：D = ε·E,  B = μ·H,  J = σ·E       （ε、μ、σ 为 3×3 静态张量）
```

- 三个方程、三个未知量（`E, H, ρ_f`）；`D、B、J` 由本构给出；
- 两个 Gauss 是约束：由 `∇·(∇×H) ≡ 0`、`∇·(∇×E) ≡ 0` + ③ 维持；
- 纯材料无粒子，③ 里没有 `J_p`。

## 2. 空间离散：Yee + subpixel（按分量 ε⁻¹ 行）

### 2.1 Yee 场位置

| 场 | 3D | 2D XZ |
|---|---|---|
| `Ex` | (i+½, j, k) | (x_{i+½}, z_j) |
| `Ey` | (i, j+½, k) | (x_i, z_j) |
| `Ez` | (i, j, k+½) | (x_i, z_{j+½}) |
| `Bx` | (i, j+½, k+½) | (x_i, z_{j+½}) |
| `By` | (i+½, j, k+½) | cell 中心 |
| `Bz` | (i+½, j+½, k) | (x_{i+½}, z_j) |

### 2.2 张量的存储与更新（Meep 的 `chi1inv` 方案）

- subpixel 初始化时，对**每个 E 分量 c**、每个 cell，算 `ε̃⁻¹` 的**一行**（3 个分量），存到该 E 分量的 Yee 位置；
  `μ̃⁻¹` 同理（对每个 B 分量存一行）；
- 更新：`E_c = Σ_d (ε̃⁻¹)_{cd} D_d`（D 取该 E 分量位置的同一 index，Meep 的 collocated 近似）；
- 各向异性材料也支持（Kottke 公式对初始各向异性有更一般形式）；
- 存储：每个材料每 cell 6 个对称分量（ε、μ、σ），另加每个 E/B 分量的 3 个 ε⁻¹/μ⁻¹ 行（可按需生成）。

### 2.3 subpixel 公式（Kottke 2008，已多源交叉核对）

> **来源与交叉验证（以正式论文为准）**：
> - **主引**：C. Kottke, A. Farjadpour, S. G. Johnson, *Phys. Rev. E* **77**, 036611 (2008)，
>   DOI [10.1103/PhysRevE.77.036611](https://doi.org/10.1103/PhysRevE.77.036611)；
>   作者版 PDF：[math.mit.edu/~stevenj/papers/KottkeFa08.pdf](https://math.mit.edu/~stevenj/papers/KottkeFa08.pdf)
>   （2008-03-25 出版；正文明确"averaging τ(ε) and then inverting τ(ε)"；
>   各向同性情形明确"averages ε⁻¹ perpendicular, ε parallel"）。
> - 预印本 [arXiv:0708.1031](https://arxiv.org/abs/0708.1031) 仅作**可机读副本**（Eq. 4/22/23 与正式版一致）。
> - 各向同性公式另与 **Meep 文档**（[Subpixel_Smoothing](https://meep.readthedocs.io/en/stable/Subpixel_Smoothing/)）和
>   **Meep 源码**（`anisotropic_averaging.cpp:201-207`）交叉核对一致；原始各向同性 subpixel 见
>   Farjadpour et al., *Opt. Lett.* 31, 2972 (2006)（DOI 10.1364/OL.31.002972）。

**各向同性材料**（与 Meep 文档、`anisotropic_averaging.cpp` 的 `eff_chi1inv_row` 一致）：

```
ε̃⁻¹ = P⟨ε⁻¹⟩ + (I − P)⟨ε⟩⁻¹,        P = n̂ n̂ᵀ
```

等价的行形式（Meep 代码）：

```
χ⁻¹_{ij} = n_i n_j (⟨ε⁻¹⟩ − 1/⟨ε⟩) + δ_ij/⟨ε⟩
```

即：**法向取调和平均、切向取算术平均**。

**各向异性材料（必须用一般形式，不能直接套投影公式）**：
把坐标转到 `x₁ ∥ n̂`，定义 τ 变换（论文 Eq. (4)）：

```
τ(ε) = [ −1/ε₁₁          ε₁₂/ε₁₁              ε₁₃/ε₁₁
         ε₂₁/ε₁₁   ε₂₂−ε₂₁ε₁₂/ε₁₁    ε₂₃−ε₂₁ε₁₃/ε₁₁
         ε₃₁/ε₁₁   ε₃₂−ε₃₁ε₁₂/ε₁₁    ε₃₃−ε₃₁ε₁₃/ε₁₁ ]
```

然后在 cell 内平均 τ、再用 τ⁻¹ 反变换（论文 Eq. (22)(23)）：

```
ε̄ = τ⁻¹{ ∫ τ[ε(y)] s(x−y) d³y }
```

τ⁻¹ 的显式形式（论文 Eq. (23)）：

```
τ⁻¹(τ) = [ −1/τ₁₁            −τ₁₂/τ₁₁                −τ₁₃/τ₁₁
          −τ₂₁/τ₁₁     τ₂₂−τ₂₁τ₁₂/τ₁₁          τ₂₃−τ₂₁τ₁₃/τ₁₁
          −τ₃₁/τ₁₁     τ₃₂−τ₃₁τ₁₂/τ₁₁          τ₃₃−τ₃₁τ₁₃/τ₁₁ ]
```

（注意：τ⁻¹ 不是普通矩阵求逆，而是论文 Eq. (23) 定义的对 τ 映射的逆；
各向同性核对：τ=diag(−1/ε, ε, ε) → τ⁻¹=diag(ε, ε, ε) ✓。）

- 各向同性时 `τ = diag(−1/ε, ε, ε)` ⇒ 回到投影公式（法向调和、切向算术）✓；
- 一般法向下：先做旋转 `ε' = R ε Rᵀ`（R 的第一列 = n̂），在旋转系做 τ 平均与 τ⁻¹，再转回 `ε̄ = Rᵀ τ⁻¹(⟨τ⟩) R`；
- `μ` 同构（用 `(B₁,H₂,H₃)` 场；若 μa=μb 该项为零）；
- **Meep 现状**：本地 `eff_chi1inv_row` 用的是**标量**平均 + 投影行，即只实现了**各向同性**公式；文档明确说"各向异性初始材料用更复杂公式"（= 上述 τ 变换）。所以本项目的张量 subpixel **必须自己实现 τ 变换**（论文 Eq. (4)(22)(23)），不能直接套投影公式；
- **σ**：Kottke 论文只覆盖 ε/μ，**不覆盖 σ**；σ 的 subpixel（阶段 (a)）没有论文依据，属于启发式，需单独验证（可参考 Opt. Lett. 37, 4802 (2012) 的色散介质界面 subpixel，但它走的是 ADE 路线，与"静态 σ"不同）；
- **验收口径**：subpixel 让**界面外/积分量**二阶；**界面逐点场至多一阶**（Meep 文档 limitation 4），明确不作验收项。

### 2.4 2D 与 3D

- 3D：按上面全 3×3 设计；
- 2D XZ：允许 **xy/yz 耦合**（Ey 与 Ex/Ez 混合），即 2D 里 **三个 E 分量都保留**，TE/TM 不再解耦；
- 2D 是 3D 的特例（y 不变），实现上按 3D 写、2D 用退化索引。

## 3. 时间离散：Yee leapfrog + 矩阵指数

### 3.1 curl 项

标准 Yee 蛙跳：`H^{n+1/2}` 用 `E^n`，`E^{n+1}` 用 `H^{n+1/2}`；空间二阶、时间二阶。

### 3.2 σ 的矩阵指数（每个 cell 3×3）

对 `ε ∂_tE = −σE + f`（`f = ∇×H`）：

```
A = ε̃⁻¹ σ̃
E^{n+1} = e^{−AΔt} E^n + (I − e^{−AΔt}) A⁻¹ (ε̃⁻¹ f)
```

- `A` 相似于 `ε̃^{-1/2} σ̃ ε̃^{-1/2}`（SPD）⇒ 特征值实、可对角化；
  `A = VΛV⁻¹`，`e^{−AΔt} = V diag(e^{−λ_iΔt}) V⁻¹`；
- **极限**：`σ=0` 的 cell（`A=0`）用 `E^{n+1} = E^n + Δt ε̃⁻¹ f`（标准 Yee 形式）；
- 对 σ 项**精确**、单调、`σ→∞` 正确；配中心化 curl 保持二阶时间精度；
- 实现：初始化时对每个 cell 预计算 `V, V⁻¹, λ`（σ 静态），每步只做矩阵乘 + exp 对角（或预先存 `e^{−λ_iΔt}`）。

### 3.3 CFL

```
Δt ≤ 1 / ( c_max √(Σ_i 1/Δx_i²) ),     c_max = 1/√(λ_min(ε) λ_min(μ))
```

- 用最小主值（波速最大）取最保守的稳定限；
- 显式 Yee 的常规 CFL；subpixel 没有 cut-cell 小胞元问题。

## 4. 电荷与 Gauss（不投影，靠一致性）

- `ρ_f` 为**节点**场（新 `FieldType`）；更新：`ρ_f^{n+1} = ρ_f^n − Δt ∇_h·(σ̃E^{n+1/2})`；
- 与 Ampere 的一致性：`∂_t∇_h·D = −∇_h·(σE)`（由 `∇_h·(∇_h×H) ≡ 0`），
  只要 **③ 与 Gauss 用同一个离散散度**、且 `D = ε̃E` 与 `E = ε̃⁻¹D` 是**离散互逆**，则
  `∇_h·D − ρ_f` 保持（初值一致 ⇒ 恒为零），**不需要投影**；
- **风险点**：按分量行（Meep 方案）的 `ε̃⁻¹` 与 `ε̃` 不是自动离散互逆的（collocated 近似），
  因此必须：
  1. 定义离散 `ε̃` 算子（D 由 E 生成）与 `ε̃⁻¹` 行**用同一套 stencil**；
  2. 加**一致性单测**：跑 N 步后检查 `max|∇_h·D − ρ_f|` 不随时间增长；
  3. 若仍漂移，再讨论兜底（投影/散度清理）——**当前设计不投影**，但该单测是验收门槛。

## 5. 边界与界面

| 情形 | 处理 |
|---|---|
| 纯 PEC（EB 固体） | **EB mask**（覆盖点 `E=0`；与现有 cut-cell 一致） |
| 电介质界面 | **subpixel**（`ε̃/μ̃` 行） |
| 金属在介质中 | **subpixel**（金属作为材料，`σ` 大或用 `ε→∞` 极限；阶段 (b) 先用 cell 平均 σ） |
| PEC-介质界面 | 以 mask 为主；界面 cell 的介质侧用 subpixel；**不做** `ε→∞` 的 subpixel 近似（避免与 mask 重复） |

**注**：界面上的逐点场仍至多一阶（Meep limitation 4）；验收用界面外/积分量（散射通量、RCS、Fresnel R/T、共振频率）。

### 5.1 介质界面的数据源（P0-b 阻塞点与解除）

**阻塞点**：`InitSubpixelRows(eb_fact)` 把 `eb_fact` 当成"介质界面"的数据源；但 WarpX 的 EB
（`warpx.eb_implicit_function`）定义的是 **PEC 固体**（ε=∞），不是两种介质之间的界面。
`eb_fact` 为 nullptr 时自然没有数据——这不是"缺介质界面"，而是**数据源用错了**。

**解除**：subpixel 与 EB **解耦**。Kottke 公式只需要三样东西：

| 需要 | 来源（新增/现有） |
|---|---|
| 两个材料的 ε（及 μ、σ） | `macroscopic.epsilon`（材料 1，现有）+ **新增** `macroscopic.epsilon2`（材料 2）；张量用 diag/offdiag |
| 界面位置（哪些 cell 被切） | **新增** `macroscopic.interface_function(x,y,z)`（φ，>0 = 材料 1） |
| 界面法向 n̂ | `n̂ = ∇φ/|∇φ|`（parser 解析梯度，或中心差分） |

**每 cell 的构造（各向同性材料，先做这个）**：

```
f      = fill_fraction(φ, cell)            // 材料 1 的面积/体积分数
n      = normalize(∇φ)                      // 界面法向（取界面质心处）
⟨ε⟩    = f ε1 + (1−f) ε2
⟨ε⁻¹⟩  = f ε1⁻¹ + (1−f) ε2⁻¹
χ⁻¹_{ij} = n_i n_j (⟨ε⁻¹⟩ − 1/⟨ε⟩) + δ_ij/⟨ε⟩
```

- **cut 判断**：cell 的 2^d 个角点 φ 符号变化即被切；`f` 用与 AMReX EB2 相同的子采样/弦面积；
- **各向异性材料**：先做 τ 变换（§2.3），再按分量存行；
- **多材料**：Kottke 公式是"两种材料、一个界面"；P0 先限制为**单一界面、两种材料**，
  >2 种材料后续用材料编号 + 逐界面处理。

**与 PEC 共存**：

- PEC 仍用 EB（`eb_fact`）+ mask，与 subpixel 无关；
- 介质界面用 `macroscopic.interface_function`，与 EB 独立；
- 一个 cell 同时被 PEC 和介质界面切：PEC 侧用 mask（或按"金属在介质中走 subpixel"用 ε→∞ 处理），
  介质侧用 subpixel；
- 若想复用 EB 的 φ 作为 **PEC 侧**界面，可把 `eb_fact.getLevelSet()` 作为**可选**输入，而不是唯一来源；
- **`eb_fact == nullptr` 时 subpixel 仍应能工作**（这是 P0-b 的独立性检验）。

## 7. 验证与基准

### 7.1 基准（全部保留）

1. **Meep subpixel 测试族**：ring resonator 频率收敛、waveguide bend 散射通量、Mie/球散射；
2. **Fresnel R/T 解析**（各向同性界面，垂直/斜 s-p、Brewster、临界角）；
3. **均匀各向异性色散**（旋转张量 vs 解析本征模）；
4. **旋转张量界面**（广义 Fresnel 或 Meep 对照）；
5. **能量/电荷守恒**（`E·ε·E + B·μ⁻¹·B`，`∇·D − ρ_f`）；
6. **σ 扫描**（阶段 (b) cell 平均；阶段 (a) Kottke 作用于实 σ）。

### 7.2 验收指标

- **P0（subpixel 平面界面）—— 已通过**：
  - `T_power` ≤1%：实测 **0.43%（32 ppw）/ 0.31%（16 ppw）** → **≥16 ppw 即达标**；
  - `R + T_power` ≤1%：实测 **0.07%（32 ppw）/ 2.2%（16 ppw）** → **≥32 ppw 达标**；
  - **`R_flux`：二阶收敛**（16/32 ppw 实测斜率 **1.9**：+20.1% → +5.4%），
    窗口取 **[2, 8] ns**（入射侧；反射 6.7 ns 到、PEC 反弹 25 ns 前）；
  - **R 的点值不作判据**：它与 `R_flux` 几乎相同（0.1335/0.1307、0.1171/0.1155），
    即不是"点值污染"，而是 `collocated ε` 的 `O(h²)` 离散误差，进 1% 需 ~64 ppw；
  - 工具：`benchmarks/cases/c02_0_pec/verify_fresnel_rt.py`，
    一次输出 6 个数（`R_flux`、`T_flux`、`R+T`、点值 `R`、`T_power`、两探针 spread）；
  - 方法：真空参考跑（`E_r = E_tot − E_ref`）；双探针行波分解不可用（`k(ω) ≠ ω/c`）；
    PML 不可用（`MEDIUM_CODE_AUDIT.md` P8），用加长域 `[-8,8]` + 窗口。
- 散射通量/RCS：二阶收敛（与 Meep 同网格对照 ≤ 2%）；
- 均匀各向异性色散：频率误差 ≤ 1% 或二阶收敛；
- 能量：无损介质漂移 ≤ 1e-6（长跑）；
- `∇·D − ρ_f`：不随时间增长（不投影前提下的硬指标）；
- **P0-b 独立性**：`eb_fact == nullptr`（无 EB）时 subpixel 路径可跑通；
- **P0-b 平面界面**：`φ = z − z0`、`ε1=1 / ε2=4`，Fresnel R/T 与解析 ≤1%；
- **P0-b 曲面**：`φ = R − r`（球/柱），与 Meep 同网格对照（RCS/散射通量）。

### 7.4 P1（各向异性 subpixel）结果与状态

界面：材料 1 = diag(1,1,1)ε₀，材料 2 = `Rz(45)·diag(1,4,2)·Rz(45)ᵀ·ε₀` = [2.5 −1.5 0; −1.5 2.5 0; 0 0 2]ε₀，
法向入射，完整坡印廷通量 `S_z = (Ex·By − Ey·Bx)/μ0`。

| 量 | 16 ppw | 32 ppw | 理论 | 斜率 |
|---|---|---|---|---|

**P1-e 状态（修正）**：

| 分量 | 耦合 | 2D 可测性 | 状态 |
|---|---|---|---|
| `εxy` | Ey↔Ex | 可测（绕 z 旋转） | **P1-d 已验证** |
| `εxz` | Ex↔Ez | 绕 y 旋转 | **已验证**（见下） |
| `εyz` | Ey↔Ez | 绕 x 旋转 | **已验证**（见下） |
| 3D 推广 | 全部 | — | 待做 |

**`εxz` 在法向入射可测（Schur 补）**：法向入射时 `∂_z D_z = 0 ⇒ D_z = 0`，于是

```
D_z = εzx Ex + εzy Ey + εzz Ez = 0  ⇒  Ez = −(εzx Ex + εzy Ey)/εzz   （纵向分量，非零）
D_t = S · E_t,   S = ε_tt − ε_tz ε_zt / εzz                          （Schur 补）
```

绕 y 旋转（`εxy = εyz = 0`）时：`S_xx = εxx − εxz²/εzz`，`S_yy = εyy`，
`n(Ex) = √(S_xx/ε0)`，`Ez = −εzx Ex/εzz`。

**两个法向入射的均匀测试（补齐 `ix2`/`iy2` 通道）**：

| 测试 | 张量（45°, diag(1,4,2)） | `ε⁻¹/ε₀⁻¹` 相关行 | `Ez` 比值 | 速度（峰值步数） |
|---|---|---|---|---|
| 绕 y（`εxz≠0`） | `[1.5 0 −0.5; 0 4 0; −0.5 0 1.5]` | x 行 `(0.75, 0, 0.25)` | `Ez/Ex = **+0.3260**（同相）` | **198**（理论 196，`0.866c`） |
| 绕 x（`εyz≠0`） | `[1 0 0; 0 3 1; 0 1 3]` | y 行 `(0, 0.375, −0.125)` | `Ez/Ey = **−0.3262**（反相）` | **280**（理论 277，`0.6124c`） |

理论值来自 Schur 补：绕 y 时 `n(Ex) = √(1.5 − 0.25/1.5) = 1.1547`；绕 x 时 `n(Ey) = √(3 − 1/3) = 1.6330`。
纵向分量 `Ez = −(εzx Ex + εzy Ey)/εzz`。**在同一时刻（主分量峰值）取比值并带符号**：
绕 y 时 `+0.3260`（与 `Ex` 同相，理论 `+1/3`）；绕 x 时 `−0.3262`（与 `Ey` 反相，理论 `−1/3`）。
速度误差均在 1% 内。

**精度声明**：峰值步是整数取样，1 步 ≈ 0.5%（196 步），故 1% 的偏差落在采样分辨率边缘；
Yee 色散在 ~30 ppw 只有 ~0.2%。因此这两个测试是 **sanity check**（通道是否接通、符号是否对），
不是 1% 精度的定量验证。要定量需抛物线插值找峰或窄带载波测相位。

**测试 1 的初始条件 caveat（已修正并复核）**：初版把初始磁场写成了 `Bz = Ex/c`（应 `By = +Ex/c`）。
`Bz(z)` 是 curl-free，不驱动 `E`，所以速度（198 步）与比值（+0.3260）**在修正前后完全不变**；
但它违反 `∇·B = 0`，且幅值从 `0.4968` 变为 `0.9273`（匹配波的能量分配）。用 `By = +Ex/c` 重跑后结论不变。

**注意**：`algo.macroscopic_tensor_test` 已在 P1 收尾中**删除**（测试钩子退役）；现在两个测试都走生产输入。
生产路径是 `macroscopic.epsilon_tensor_xx … _yz`（6 个 parser，材料 1）与 `epsilon2_tensor_*`（材料 2），

|---|---|---|
| 有 `epsilon_tensor_*`、无 `interface_function` | **bulk** | 每个 cell 的行 = `inv3_sym(ε₁)` 的行；材料 2 被忽略并打印提示 |

**输入组合的守卫（防止静默回退）**：

|---|---|

```
is_isotropic(A): off-diagonal == 0 && A_xx == A_yy == A_zz
```

### 7.7 P2 有损介质：冻结的 5 个设计决定

| 决定 | 取值 | 理由 |
|---|---|---|
| 存什么 | `M1`、`M2` 各 9 分量，cell-centered | 每步两次 3×3 乘，无 `eigh` |
| 谁存 | **只 `σ>0` 的 cell**；`σ=0` 走原分支 | 保 P0/P1 逐位回归 |
| 用哪个 ε | **cell-centered 的 ε**（与 σ 同位置） | `A=ε⁻¹σ` 是 3×3 耦合，必须同一套 ε；curl 项仍用逐分量 χ⁻¹ 行（collocated，O(h)） |
| dt | 初始化时算好，**断言运行中不变** | 避免 stale `M1/M2` |
| J 项 | `E = M1·E + M2·(curlH − J)` | 与 `σ=0` 的 `−dt ε⁻¹ J` 一致 |

公式（`B = ε^{-1/2}σ ε^{-1/2}` 对称，`A = ε^{-1/2} B ε^{1/2}`）：

```
M1 = exp(-A dt)                  = eps^{-1/2} exp(-B dt) eps^{1/2}
M2 = (1 - exp(-A dt)) A^-1 eps^-1 = eps^{-1/2} [(1-exp(-B dt))/B] eps^{-1/2}
sigma = 0  =>  M1 = I,  M2 = dt eps^-1   （逐位退化为 Yee）
```

三个要防的坑：

1. **快路径必须逐位**：`σ=0` 的 cell 走原分支，不做 `exp(0)=1` 的重算；
2. **J 用同一个 `M2`**：`M2·(curlH − J)`，不要另算 `β0 χ⁻¹ J`；
3. **`σ>0` 且 ε 各向异性**：`A` 非对称，必须走 `ε^{-1/2}σ ε^{-1/2}` 对称化，不能直接 `eigh(A)`。

数学层已验证（`sigma_exp_test.cpp` vs numpy，6 例 `max rel = 1.998e-15`，`σ=0` 逐位 0）。

### 7.9 P2-b 定案：介质传导电荷 ρ_medium 与 Gauss 一致性

**位置与算子**（与 Yee 网格的 `∇·D` 严格同位置）：

```
rho_medium: 节点 (i,j)          （2D XZ 的 cell corner）
Jx: x 面（与 Dx 同位置）   Jz: z 面（与 Dz 同位置）
散度: 与 Gauss 完全相同的 "面->节点" 算子（DownwardDx + DownwardDz）
```

**时间层**：`rho` 与 `E/D` 同在**整数层**；`B/H` 半层。
Gauss 律 `∇·D = ρ` 是**同层**约束，所以 `ρ` 不能放半层。

**电流必须用步内平均**（这一条是原方案没写的关键）：

```
rho^{n+1} = rho^n - dt * ∇_h · (sigma * c * E^n)
c = (1 - e^{-a dt})/(a dt),        a = sigma/eps
sigma -> 0 时 c -> 1，该项为零（快路径）
张量 sigma 时 c -> (I - e^{-A dt})(A dt)^{-1}，与 M1/M2 同一套
```

**1D 玩具验证**（`benchmarks/cases/c02_0_pec/gauss_toy.py`，1D Yee、无 curl、200 步）：

| 电流形式 | `max\|∇·D − ρ\|`（归一化） |
|---|---|
| **步内平均 `c`** | **`1.598e-15`**（机器精度） |
| 瞬时 `σE^n` | `2.286e-09` |
| 瞬时 `σE^{n+1}` | `2.286e-09` |

时间平均比瞬时好 6 个数量级；恒等式 `exp(-a dt) == 1 - a dt c` 逐位成立。
**只对齐空间散度不够，时间平均是另一半。**

**存储：新建 `FieldType`，不复用 `rho_fp`**。理由：

1. `rho_fp` 每步被粒子沉积（`SyncRho`）重写，介质电荷会被**直接抹掉**；
2. `ρ_total = ρ_particle + ρ_medium` 是两个物理源，混放后无法区分；
3. `ProjectionDivCleaner` 用 `rho_fp`，被污染后语义就错了；
4. 纯材料算例"看起来能跑"只是把 bug 推给未来。

**改动清单**（约 200 行）：

```
1. Source/Fields.H         枚举加 rho_medium_fp（紧跟 rho_fp）
2. AllocateLevelMFs        节点 (1,1) 的 MultiFab，初值 0
3. field register          注册，供诊断/测试读取
4. MacroscopicEvolveE      每步 rho += -dt∇_h(σ c E^n)
5. 诊断                    plotfile / reduced diag（先不做 checkpoint）
6. 单测                    均匀 ε/σ、周期边界、rho(0)=∇_h D(0)
```

**单测要点**：

- `ρ(0) = ∇_h·D(0)` 必须**直接写**（否则测的是初值误差，不是漂移）；
- 纯材料算例 `ρ_particle = 0`，Gauss 检查就是 `∇·D = ρ_medium`；
- 有粒子时必须用 `ρ_medium + ρ_particle`（写进文档，别留歧义）；
- 判据：`max|∇_h·D − ρ_medium|` 在 N 步内不增长（理想 ~机器精度）。


### 7.10 E3/A3 张量界面 R/T 验收（B1-B4 闭合）

**方法（c03_medium/tensor_interface/analyze.py, `bc7ed4d`）**：确定性分析，自带 selftest。

```
载频固定 omega = 2*pi*c/lam（输入已知，不用 FFT 找峰——截断下峰位会漂到旁瓣）
每个脉冲用各自窗口: 中心 = 发射时刻 + 走时, 半宽 = 5 tau
E_inc  = DFT(runB, qrefl, 入射窗)   E_refl = DFT(runA - runB, qrefl, 反射窗)
E_tr   = DFT(runA, qtrans, 透射窗)  E_trref = DFT(runB, qtrans, 透射窗)
selftest: 合成数据精确恢复 R=0.145898 T=0.854102, R+T=1.000000   PASS
```

旧方法（FFT 找峰 + 单窗口）的 R 在 0.26-4.4 之间跳，是不稳定 omega + 截断的典型症状；
该方法已废弃。

**算例**：域 ±6、源 z=-3（t0=16ns, tau=2ns）、界面 z=0（eps1=eps0 -> eps2 张量 diag(4,5,6)eps0）、

真空参考 runB（去 interface 与张量）。

| ppw (介质内) | n_cell | R | 偏差 | T | 偏差 | R+T |
|---|---|---|---|---|---|---|
| 17.9 | 480 | 0.150017 | +2.82% | 0.860733 | +0.78% | 1.0108 |

**结论**：B1-B4（张量 parser + cell-centered 张量 MF + Kottke/bulk/fill_sigma_mats 读局部张量）

1. 反射分离必须 runA - runB 且各脉冲用各自窗口，共用窗口必截断；

### 7.11 E6 导体板衰减：未通过（sigma 空间变化时 sigma>0 区 E 恒为零）

**目标**：导体板（`sigma/(omega eps0) = 6`），板内两探针 `|E(z2)/E(z1)| = exp(-alpha dz)`。

**结果：未通过。** 板内探针恒为零（`B` 亦为零），真空侧正常（1.1e6）。**这是一个真实缺陷，
不是判据问题**，根因未定位到代码行。

**已排除（每条都有实测证据）**：

| 怀疑 | 实验 | 结论 |
|---|---|---|
| 探针位置/插值 | 探针在 cell 边界（x=0）vs cell 中心 | **cell 边界上 FieldProbe 读 0**，移到 cell 中心后 c1=8.6e4。已修正本 case 的探针 |

| 指数步整体失效 | `sigma = 1e-6` 或 `0.1` 全域（常数） | 源附近有场（8.6e4 / 1.85e4）-> 常数 sigma 时指数步工作 |
| 循环盒子错 | 打印 `tb` 与 `sigma` 的 FAB box | `tb_lo=(0,0) sigfab_lo=(0,0)` 逐 grid 一致；`tb=(0,0)-(63,63)` 非空 |

| M1/M2 未填/填错 | 打印 `|M1|max`、`|M2|max` | `sigma=1e-6`: M1=0.9999967、M2=3.33（与 `A dt = 3.33e-6` 自洽）|
| enew 计算/写回 | kernel 内累加 `|rhs_y|`、`|enew_y|`，并打印写回后的 `Ey` | `sigma=1e-6` 时 rhs=3.9e4、enew=1.2e6、写回 Ey=1.29e5 -> 写回成功 |

**关键对照（决定性）**：

```
sigma = 0             -> 全域探针 9.9e5       （走 BE）
sigma = 1e-6 全域      -> 源附近 8.6e4         （走指数步，M1 ~ 1）
sigma = 0.1  全域      -> 源附近 1.85e4        （走指数步，M1 = 0.717）
sigma = 0.01*(z>0)    -> z>0 全部为 0，z<0 正常（走指数步，M1 = 0.967）
sigma = 0.1*(z>0)     -> z>0 全部为 0，z<0 正常（走指数步，M1 = 0.717）
sigma = 0.1*(z>0.5)   -> 探针(z<0.5)全部正常    （探针处走 BE）
```

**所以触发条件是 "sigma 的空间分区 + 探针落在 sigma>0 区"**，与 sigma 大小（0.01 与 0.1 同）
和 M1 的强弱无关。常数 sigma（全域）永远正常。

**影响范围**：

- S5（有损平面波，`-0.22%`）用**全域常数** `sigma=0.01` -> **不受影响**（已确认输入带 `subpixel=1`
  且走指数步）；
- P2-a 的弛豫/刚性测试也都是全域常数 sigma -> 不受影响；
- **任何"有损层/导体板"（sigma 只在部分区域）目前不可用**：sigma>0 区场为 0。

**后续定位（已做，仍未通过）**：

1. **因果性排除**：`sigma=0`、同几何、同 `stop_time=60 ns`、同探针（z>0）-> z=0.0156/0.0469/0.2344
   在 **26.8–27.5 ns** 就有 `9.88e5`。时间充分，不是"波没到"。
2. **板内单个 cell 的精确读数**（`i=320, j=321`, z=0.0469，`sigma=0.1`）：
   `M1_00=0.7168`、`M2_00=2.832`（正确）、`|eold_y|=0`、`|enew_y|=0`、`Ey_written=0`、`J=0`。
3. **界面附近剖面**：`Ey(319)=-4.55`（探针 z=-0.1 处 1.1e6）、`Ey(320)=-0.064`、
   `Bx(319)=8.8e-10`（正常应 ~1e-3）、`Bx(320)=Bx(321)=0`。

**所以界面处 E 与 B 同时被压到 ~0，形成自锁**：

```
E(320)=0  ->  Faraday 的 curl 用 E(320)/E(321) ->  Bx(321)=0
E(319)!=0 ->  Bx(320) 应由 (Ey(320)-Ey(319))/dz 驱动，实测仍为 0   <- 新的可疑点
```

**已做的一个正确修复（但不足以修复 E6）**：`sigma_arr(cell)==0` 的 cell 强制 `sigma_interp=0`，
不让导体值经 face 插值给真空 cell 带来阻尼（否则界面真空侧被压到 ~0）。
P0 回归 `sigma=0` 逐位不变（`0.1335 / 0.8513`），但板内仍为零（板内是 `sigma>0` 的 cell，走指数步，
不经过这条路径）。

**验证该修复是否解开自锁（已做，结论：没有）**：修复后在界面处打印（i=320，41 ns）：

```
Ey(cell 319,320,321) = -5.69 , -0.244 , 0      (探针 z=-0.1 即 cell 316 处仍有 1.1e6)
Bx(face 319,320,321) =  3.4e-9 , 0 , 0
```

即 **界面真空侧的 Ey 仍被压到 ~5.7（而不是 1e5 量级），Bx(face 320) 仍恒为 0**。
所以"σ=0 的 cell 不继承插值阻尼"是**正确但无效**的：自锁不在 σ 插值这一侧。

**因此下列补强不会解决 E6**（它们都作用在 `sigma_interp` 上）：

这些仍是应该做的正确化（staircase 一阶、界面 O(h)），但 E6 的阻塞点在 B 侧：

```

```

## 9. 风险与开放问题

1. **界面点值一阶**：Meep 文档明确；若验收要求界面逐点二阶，subpixel 单独做不到（需表面电流修正/换框架——本路径不含）。
2. **不投影的 Gauss 精确性**：按分量行方案需要"离散互逆"的 `ε̃` 算子；单测不过则需回到用户决定（投影/清理）。
3. **σ 的 subpixel**：阶段 (a) 是启发式（Kottke 公式源自无损实 ε；复 ε 会频率依赖）；需与阶段 (b) 对比，必要时用色散界面 subpixel 文献的方法。
4. **2D 全耦合**：xy/yz 耦合使 TE/TM 不再解耦，更新需三分量同时在场；性能与实现复杂度上升。
5. **两条路径互斥（不是实现缺口，是设计决定）**：subpixel 把界面抹成体积等效 ε̃（Yee 网格），
   ECT 用共形几何切格（`Bx·Lx`、开放面积）。把 `χ⁻¹` 行塞进 ECT 的共形环量等于对同一个界面
   做两次处理，既不是纯 subpixel 也不是纯共形，**没有参考实现可对照、误差无法归因**。
   因此 `EvolveECartesianECT` 保持标量 `inv_epsr`，不接 subpixel 行；
   介质/张量算例统一用 `maxwell_solver = yee`。
6. **张量本征分解的稳健性**：`ε̃⁻¹σ̃` 在极端对比下条件数大；用 `ε^{-1/2}σ ε^{-1/2}` 的对称形式做特征分解更稳。

### 7.6 L0 张量单元测试结果（p1_tensor_reference.py + p1_tensor_test.cpp）

37 个固定种子用例（`p1_cases.csv`）覆盖：双各向异性 `rot_rot`、`n→−n`、切向基旋转、
`f` 端点、2D 特例、极端对比（1e6）。

**首测：37 例中 25 例失败，max rel err `2.383e-01`。**

失败分布给出了根因：`*_2d` 全过、所有 3D 全错 →

```
frame(n) 硬编码成 2D 特例：
  R = [nx 0 -nz; 0 1 0; nz 0 nx]      // 忽略 n_y、未归一化
Python 参考用 3D 通用 Gram-Schmidt：
  t1 = normalize(a - n(a·n)),  t2 = n × t1,  R = [n, t1, t2]
```

影响范围（重要）：P0 走 `chi_inv_isotropic`（不经 `frame`）→ 不受影响；
P1-d / `ix2` / `iy2` 全用 `n=(0,0,1)` → 恰好落在特例里，所以一直没暴露；
**只有 3D 任意法向会错**。

修复后：37 例全过（`extreme` 因 1e6 对比下闭式逆的舍入，阈值单独放到 `1e-10`）。
P0 回归逐位不变（`R_flux=0.1335`、`T_flux=0.8513`、`R+T=0.9847`）。

| 项 | 内核实际代码 | 判定 |
|---|---|---|
| L1.2 行列映射 | `Ex = alpha*Ex + beta0*(ix0*Dx + ix1*Dy + ix2*Dz) - beta0*ix0*jx` | 完整**行 × 向量** ✓ |
| L1.3 stagger | `Dy = DownwardDz(Hx,...,i,j,k,0) - DownwardDx(Hz,...,i,j,k,0)` | **same index**（collocated，Meep 约定）✓ |
| L1.4 对角 | `has_sub=false` 时 `ix1=ix2=0`，退化为 `beta*eps*(1/eps)*Dx` | ✓ |

**一个无关自由度**：`chi^-1` 对称（行 = 列），所以“行×D”与“列×D”**在数值上不可区分、
也不影响结果**。L1.2 真正要防的是“只乘 `D_c` 而漏掉另两个分量”，而这已由 `ix2`/`iy2`
测试钉死（绕 y 时 `Ez/Ex = +1/3`，若 `Ez` 只乘 `Dz` 则为 0）。

**结论（L1 收口，不加钩子）**：

```
L1.2：由 ix1/ix2/iy1/iy2 覆盖（对称 chi^-1 下行列不可分，也不影响结果）；
L1.3：审计确认 same-index = Meep 约定（设计选择，非 bug）；运行时 index 测试暂缓；
收敛率：T2-s 3.1x，与 T1 法向的 3.7x 同量级，不归因于 collocated。
```

理由：`tensor_test` 刚退役，再加 test-only 钩子有卫生成本；L1.3 只确认一个已知设计，
信息增量低。若将来要量化 collocated 的影响，正确的实验是**旋转张量界面的 16/32/64 收敛**
（collocated 只作用于 off-diagonal，各向同性 `chi^-1` 是对角，测不出），属可选新算例。
