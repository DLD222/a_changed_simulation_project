## 1. F-1：几何实验差半格（我的错）

### 1.1 原做法

`/tmp/geom_order.py` 把 `Lx` 放在 `(x_i, z_{j+1/2})`，但 `x_i` 取的是**格心**
（`x[i] = xe[i] + h/2`），所以 `exact` 积分跨的是 `[xe[i], xe[i+1]]`——**整个 cell**。

而代码里 `Lx` 在 `Bx` 的位置：`x_i` 是**节点** `xe[i]`，对偶线跨 `[xe[i]−h/2, xe[i]+h/2]`
（半个 cell + 半个 cell）。所以我的"公式（用 cell `i−1` 与 `i`）"和"参考线"不是同一个对象。

### 1.2 更正后的数字（对偶线正确位置）

| `n` | `h` | 方案 B RMS (m) | 方案 A RMS (m) | `A_y` RMS (m²) |
|---|---|---|---|---|
| 40 | 0.2000 | 0.02864 | 0.02946 | 6.887e-03 |
| 80 | 0.1000 | 0.01415 | 0.01443 | 1.315e-03 |
| 160 | 0.0500 | 0.00835 | 0.00932 | 2.454e-04 |
| **阶** | | **1.02 / 0.76** | **1.03 / 0.63** | **2.39 / 2.42** |

（复核用独立脚本给出同样量级：B `0.0286/0.0142/0.0084`、A `0.0295/0.0144/0.0093`。）

### 1.3 结论

- **判断不变**：B 与 A 都是一阶，A **仍略差**（RMS 大 3–11%），所以"删掉方案 A、直接 level-set"成立；
- **数字要改**：原写的 `0.0412/0.0160/0.0058`、阶 1.4–1.5 是格心线的统计，**不能当代码的几何基线**；
  正确值 `0.029/0.014/0.008`、阶 ~1.0 与仿真观测的 1.06–1.28 更自洽（1.4–1.5 反而与仿真矛盾，
  这本身就是原实验有问题的信号，我当时没抓住）。

## 2. F-2：F3 在 PEC 内制造热斑，而 L2 环带看不见（真实缺陷）

### 2.1 原论证

"F3 把 `Ey` 判据从 `ly==0` 改成 `A_y<=0` 后，L3 45° 与米氏三档的结果**逐位不变** → 掩膜不是瓶颈。"

### 2.2 字段级对比（同一算例：米氏 TE 80²、`ect_conformal_E=2`、单 grid）

| 量 | F3 前（`ly` 判据） | F3 后（`A_y<=0`） |
|---|---|---|
| `max\|Ey\|`（全网格，末帧） | **1.68e6** | **7.13e6** |
| `max\|Ey\|` 在 PEC 内（`r<0.9`） | **0.0** | **7.13e6** |
| 环带 L2（`1.5R–2.5R`） | 0.9321 | 0.9321（4 位一致） |
| L3 45° `mean r` | −1.0459 | −1.0459（4 位一致） |

热斑位置 `r ≈ 0.86`，**正好落在环带判据的内侧盲区**。而且它不衰减（时间序列 `5.2 → 7.1e6`），
说明是持续注入而非瞬态。

### 2.3 机理

F3 放开的是"`A_y > 0` 但很小"的节点。旧判据 `ly == 0` 恰好把它们冻住。
这些节点上 `Ey += c²dt(…)/A_y` 的 `1/A_y` 很大 → 在 PEC 内/边界形成热斑。

这正好是 `C_SIDE_DESIGN2.md` R2 警告过的"小 `A_y` 放大"，也是 `C_SIDE_RESEARCH2.md` §3.3 说的
"抬分母必然破坏配对"的具体后果。

### 2.4 处置

已回退：`MarkUpdateECellsECT` 的调用不再传 `dual_A_y`（`dual_A_y` 形参保留，等稳定化标定后再用）。

验证（回退后，同一算例）：

```
mask = ly  ->  max|Ey| = 1.676e6，PEC 内 = 0.000e+00，环带 = 1.656e6
```

PEC 内严格为 0，热斑消失。

### 2.5 这条发现的真正价值：**判据盲区**

"L2 环带不变"曾被当作"掩膜改动无害"的证据，但环带是**人为选的窗口**（`1.5R–2.5R`），
PEC 内部不在其中。**任何只报告环带 L2 的验收，都无法发现导体内部的热斑。**
后续所有 C 侧算例必须同时报告：`max|E|`（全网格）、`max|E|`（PEC 内 `r < 0.9R`）、环带 L2。

## 3. F-3：只抬分母的稳定化不足（A_stab 标定）

### 3.1 新增机制

`algo.ect_conformal_E_Astab`（默认 `0.1`，单位 `dx*dz`）：
把 `0 < A_y < A_stab` 抬到 `A_stab`，`A_y == 0`（fully covered）保持 0（掩膜仍冻结它）。

### 3.2 扫描结果（米氏 TE 80²，末帧）

| `A_stab`（× dx·dz） | 全网格 `max\|Ey\|` | PEC 内（`r<0.9`） | 环带（1.5R–2.5R） |
|---|---|---|---|
| 0.001（≈无） | 7.13e6 | 7.13e6 | 1.66e6 |
| 0.1（默认） | 6.89e6 | 6.89e6 | 1.66e6 |
| 0.5 | 4.05e6 | 2.40e6 | 1.66e6 |
| 2.0 | 2.87e6 | 1.34e6 | 2.62e6 |
| 10.0 | 3.47e6 | **1.84e5** | 2.12e6 |

### 3.3 结论

1. 热斑确实由小 `A_y` 引起（`A_stab` 越大压得越狠）；
2. 但要压到 `1e5` 量级需要 `A_stab ≈ 10`，此时环带场已被抬高 **27%**（1.66e6 → 2.12e6）
   —— 等于**放弃共形、退化为阶梯**；
3. 因此"只抬分母"是**半侧稳定化**，不足以支撑"放开 cut 节点"。完整的对偶稳定化
   （分子/分母同时限制的 BCK 式，或 Dey–Mittra 的阈值丢弃）必须排在 **level-set 之前**。

## 4. 对计划的影响

### 4.1 顺序调整（取代旧顺序）

```
旧：F3 放开掩膜 → F4 方案 A（已作废）→ level-set → 稳定化
新：A_stab 分母下限（已有，阈值待标定）
      → 完整对偶稳定化（BCK 式 / DM 阈值）
        → level-set 精确几何（scheme C）
          → 测量侧（RCS 减数值入射、地板并列、>= 4 档）
```

### 4.2 作废项

| 项 | 处置 | 依据 |
|---|---|---|
| F4（方案 A 面分数） | **作废** | 对偶线位置复算：A 比 B 差 3–11%，阶相同（F-1） |
| F3（掩膜放开为 `A_y<=0`） | **回退** | PEC 内热斑 7.1e6（F-2） |
| "先 level-set 再稳定化" | **反转** | 几何精确不消除 `1/A_y` 放大（F-3） |

### 4.3 验收判据新增

任何 C 侧算例的验收表必须包含三行：

```
max|E|（全网格）             -- 发现热斑
max|E|（PEC 内 r < 0.9R）    -- 必须为 0 或 <= 机器零
L2（环带 1.5R-2.5R）         -- 原有的精度指标
```

缺第二行时，F-2 这类缺陷会完全隐形。

## 5. 方法论教训

1. **几何实验必须对着"代码里那个量所在的位置"做**，而不是对着"看起来等价"的位置。
   半格的位置误差会让阶数从 1.0 变成 1.5，而且方向看起来"更合理"。
2. **指标窗口是人选的，缺陷往往长在窗口外**。环带 L2 看不见 PEC 内，正如相对误差看不见零分量
   （`Bz` 的 `rel=1.0` 假 FAIL，此前已踩过一次）。判据要覆盖"最坏点"而不只是"感兴趣区"。
3. **"结果逐位不变"只能证明被测量的量不变**，不能证明场不变。要下"无影响"的结论，必须比字段。
4. **与仿真观测矛盾的理论数字是好信号**：几何实验给 1.4–1.5、仿真给 1.06–1.28，我当时写
   "一阶误差源换了位置"就过去了，实际上那是实验本身错位的提示。
