## 2. 证据与排除项

### T1 法向 Fresnel
- 真空参考跑 + 双探针 + 完整坡印廷通量 `S_z=(Ex·By−Ey·Bx)/μ0`；
- 16 ppw：`R_flux 0.1335(+20.1%)`、`T 0.8513`、`R+T 0.9847`；
- 32 ppw：`R_flux 0.1171(+5.40%)`、`T 0.8778`、`R+T 0.9949`；
- 收敛率 ≈O(h²)（3.7×/倍）。

### T3 Snell
- x 方向 **periodic**、z 方向 pec；初始波包 `Ey=exp(−((z−z0)/w)²)cos(kx x+kz z)`，`kx=π`（周期兼容）、`kz=5.4414`；
- `kx` 在真空（4 个时刻）和界面两侧（5 个时刻）均为 `3.1416`，`Δkx=0.0000`；
- 折射角未测：kz 相位法受界面驻波影响（`λ2=0.516`、段内 ~5 周期、unwrap 跳错）；按"kx 守恒 + T5 色散"结案，角度不再追。

### T5 / T6
- T5：均匀介质宽脉冲，34 ppw，相速度 `−0.173%`；
- T6：32 ppw，能量 `−0.51%`。

### T7 圆盘
- 解析极点：l=3 `f=0.23390, Q=84.8`；l=4 `0.2933, 367`；l=5 `0.3506, 1705`；
- Meep：res=20 `0.23361/86.6`；res=40 `0.23381/85.6`；res=80 `0.23387/85.8`；
- WarpX：fft `+0.17%`（2e4 步）、`+0.63%`（2.2e5 步）、Prony `0.23347`（−0.18%）、`Q=75.4`；
- Q 的边界效应：PEC 盒（盒模式）→ 75.4；σ 海绵（反射）→ 118.8（上界）；真值 85（Meep/解析）；
- 结论：Q 在 P8 解决前无法给出可比辐射 Q。

### T9 介质 Mie
- **已修复的 bug**：无 interface 的对角分支只填 comp 0（`inv(i,j,k,0)`），Ey/Ez 的 `χ⁻¹_yy/zz=0` → 场被 `α` 衰减到零；修复后 A≡B（`ead9cbe`）；
- 真空参考同源（`macroscopic` + ε=1）；
- 尝试：单帧 102% → DFT `[18,28]` 141% → `[14,28]` 152%；θ 四种约定 145–154%；
- **已排除**：窗口（4 种）、θ 约定（4 种）、参考跑不同源、两跑 dt 不一致（实际均为 `4.717308673e-11`）；
- **本轮新增（限定性结论）**：σ 海绵（`sigma_function = if(r>2.5, 1.0*((r-2.5)/1.5)^2, 0)`，
  `σ_max=1.0 S/m`，**未做阻抗匹配**）使 `|S|max` 从 1.21 涨到 3.52、`L2` 从 1.516 升到 2.853。
  由于该海绵本身就会散射（`|S|max` 涨 3 倍即是证据），这个检验**不是对 P8 的公平检验**；
  正确的结论是 **"边界处理不是 T9 图样问题的主因"**，而不是 "P8 已被证明无关"。
  **P8 对 T7-Q 的阻塞仍然成立**（那是 PML 用于开放边界辐射 Q 的场景）。
- **未排除**：`E_inc0` 可能被边界反射污染（全时间轴 DFT 含晚期反射）、
  窗口对不同 r 的完整性、脉冲宽带（`tw=1ns` → 带宽占载频 23%）vs 解析单频、
  解析 `scattered()` 与数值的极坐标/原点约定（四种 θ 都试过，均 145–154%，故不是简单的 atan2 参数顺序）；
- 注：`E_inc0` 是**实测**（真空跑在 (0,0) 的复振幅），激光在 z=−2 的 168° 相位已被除法消掉——"相位参考面"不是问题（除非 E_inc0 被 PML 反射污染）。

## 3. 时间/空间尺度检查清单（强制前置）

```
1. T_sim ≥ t_drive_end + 10τ            （长度）
2. t_drive_end ≪ τ                       （驱动必须短于衰减；T7 模投影失败即此条）
3. Δf = 1/T_sim ≪ γ/π                    （线宽分辨率；注意是 γ/π）
4. 探针/投影是否单模                     （模式分离）
```

配套事实：`τ = Q/(πf)`；洛伦兹 FWHM = `γ/π`；FP 峰间距 `c/(2n2 d)`；脉冲位置 `z = z0 + v(t−t0)`。
