## 2. 文档 §3.2 的问题：几何实验位置差半格

### 2.1 文档的做法

文档脚本把 `Lx` 放在"`(x_i, z_{j+1/2})`"，但它的 `x_i` 取的是**格心** `x[i]=xe[i]+h/2`，
`exact` 积分跨 `[x_i−h/2, x_i+h/2] = [xe[i], xe[i+1]]`（整个 cell）；而代码的 `Lx` 在 `Bx` 位置，
`x_i` 是**节点** `xe[i]`，对偶线跨 `[xe[i]−h/2, xe[i]+h/2]`（半格+半格）。

所以文档的 B/A 公式（用 cell `i−1` 与 `i`）与它的"格心线"错开了半格——**公式与参考线不是同一个对象**。

### 2.2 修正后的数字

| 方案 | 40² (h=0.2) | 80² | 160² | 阶（40→80 / 80→160） |
|---|---|---|---|---|
| B（当前实现） | 0.02864 | 0.01415 | 0.00835 | **1.02 / 0.76** |
| A（修正版四面平均） | 0.02946 | 0.01443 | 0.00932 | **1.03 / 0.63** |
| A_y | — | — | — | 1.95 / 1.99（另一组口径 2.39/2.42） |

- **结论不变**：A 不比 B 好（甚至略差），两者都是一阶 → 文档"删掉 F4、直接 level-set"的判断正确。
- **但要改数字**：文档的 `0.0412/0.0160/0.0058` 与 `1.4–1.5` 是格心线的统计，不能当代码的几何基线；
  代码的真实几何误差约为 `0.029/0.014/0.008`、阶 ~1.0（与仿真观测的 1.06–1.28 更自洽）。
- **顺带**：我之前建议的"方案 A（修正版）"在正确位置复算下同样无收益，**该建议应撤回**；
  文档的判断（A 无收益）比我的建议更接近事实。

## 3. 文档 §3.4 的问题："掩膜不是瓶颈"是 L2 指标的盲区

### 3.1 文档的论证

"F3 把 `Ey` 判据从 `ly==0` 改成 `A_y<=0` 后，L3 45° 与米氏三档的结果**逐位不变**" → 掩膜不是瓶颈。

### 3.2 实际字段对比（同一算例、F3 前 vs F3 后）

| 量 | F3 前（15:47 二进制） | F3 后（17:11 二进制，含 F3） |
|---|---|---|
| `max\|Ey\|`（末帧 t=4.5e-8） | **1.68e6**（r≈1.16） | **7.13e6**（r≈0.86，**在 PEC 内**） |
| 时间序列 `max\|Ey\|` | 1.25 → 1.83 → 2.02 → 1.68e6 | **5.22 → 4.95 → 8.31 → 7.13e6** |
| 与 F3 前差分 | — | `max\|Δ\| = 7.1e6`；约 2% 的点差 >1% 幅值 |
| 环带 L2（1.5R–2.5R） | 0.9321 | 0.9321（4 位一致） |
| L3 45° | `mean r = −1.0459`，斜率 −1.51% | 同左（4 位一致） |

**解释**：F3 放开的是 `A_y>0` 但**很小**的节点（旧判据 `ly==0` 恰好把它们冻住）。这些节点上
`Ey += c²dt(…)/A_y` 的 `1/A_y` 很大 → 在 PEC 内/边界形成**持续热斑**（5–8e6，不衰减）。
环带 L2 取 `1.5R–2.5R`，热斑在 `r≈0.86`，**指标看不见**——所以"L2 逐位不变"不能推出"场不变"。

### 3.3 为什么这很重要

- 文档的 §0.3"掩膜不是瓶颈"、§3.4"已被实测排除"因此**不成立**；F3 不是"无害的正确性修正"，
  它暴露了计划里 R2 警告的"小 `A_y` 放大"问题。
- 这也说明文档的"先 level-set 再稳定化"的顺序是**反的**：level-set 只换几何，
  若小 `A_y` 仍存在，热斑照样出现（甚至更明显，因为几何更"锐"）。
- 文档对 CHECK 的"176/356/702"口径的说明（"很可能用的是 `volfrac>0`"）不准确：CHECK 用的是
  **精确 `A_y>0` + 精确 `ly=0`**；不过更关键的是字段实验证明两套掩膜确实不同。

## 4. 修正建议

| # | 建议 | 理由 |
|---|---|---|
| 1 | **F3 的验收加"PEC 内/边界 `max|E|` 不劣化"** | 环带 L2 对 PEC 内热斑是盲区（§3） |
| 2 | **把 `A_stab` 提到 level-set 之前** | 小 `A_y` 是 1/A 放大的来源；几何精确化不能替代稳定化 |
| 3 | 掩膜判据改为 `A_y <= A_stab`（或 `A_y <= 0` 且 `A_y` 已抬到 `A_stab`）再放开 | 既保留"cut 节点参与更新"，又不产生热斑 |
| 4 | 文档 §3.2 的 RMS/阶数改用对偶线位置（或直接引用本文 §2.2 的数字） | 避免"1.4–1.5 的几何阶"与仿真 1.06–1.28 的矛盾 |
| 5 | 保留"删 F4、直接 level-set"的判断 | 独立复算支持：A 无收益 |
| 6 | 保留测量侧修正（RCS 减数值入射、真空地板并列报告、≥4 档） | 与本文复核一致 |
