## 4. 米氏收敛阶复跑（TE，单 grid）

命令：`analyze_mie_convergence.py /tmp/mie_run/{c0,c2} ey`（`c0` = 掩膜 Yee，`c2` = 共形 E `=2`）。

| 开关 | n=40 L2 | n=80 L2 | n=160 L2 | 近场阶数 | RCS 阶数 |
|---|---|---|---|---|---|
| `c0`（Yee） | 1.9220 | 0.7939 | 0.3270 | **1.278** | **1.756** |
| `c2`（C 侧） | 1.9047 | 0.9321 | 0.4395 | **1.058** | **1.770** |

与报告 §3.4 完全一致（报告：`1.28/1.76` 与 `1.06/1.77`；80²/160² 数值 0.794/0.327 与 0.932/0.440 也一致）。

### 4.1 估计器交叉验证（排除"DFT 伪像"）

原脚本用"最后 8 帧的 8 点 DFT"提取谐波幅值。8 帧在时间上**不一定跨越整数周期**，理论上会有幅值/相位偏差。
本次用两种独立估计器交叉验证：

1. 8 帧 DFT 的幅值 / 全序列最小二乘幅值 = **1.560 / 1.481 / 1.279**（40/80/160）——确实有偏差，且随分辨率变化；
2. 但把**无偏**的全序列最小二乘幅值（取正确的相位约定，即 `conj`）代入同一 L2 判据，得到：

| 开关 | LSQ L2 (40/80/160) | 局部阶数 | 对比脚本阶数 |
|---|---|---|---|
| `c0` | 1.930 / 0.793 / 0.326 | 1.283 / 1.283 | 1.278 ✅ |
| `c2` | 1.914 / 0.941 / 0.437 | 1.024 / 1.107 | 1.058 ✅ |

→ **报告的阶数不是 DFT 偏差造成的伪像**：无偏估计器复现了同样的 L2 和阶数。这个交叉验证很重要，
它把"测量方法"从嫌疑名单里排除了（但测量地板仍在，见 §5.2）。

## 5. 为什么收敛阶不接近 2

分两层：**物理层**（离散格式本身是一阶）和**测量层**（有限分辨率下"入射波"不是理想平面波、RCS 减的是解析入射）。

### 5.1 物理层：`Lx/Lz` 是一阶，`A_y` 是二阶

纯几何实验（解析圆 + 精确 volfrac + 方案 B 公式，40/80/160 三档）：

| 量 | 绝对 RMS 误差（m 或 m²） | 观察阶 |
|---|---|---|
| `Lx`（Bx 处，沿 x 开放长度） | 0.0973 → 0.0477 → 0.0266 m | **~1.0** |
| `Lz`（Bz 处，沿 z） | 0.0973 → 0.0477 → 0.0266 m | **~1.0** |
| `A_y`（节点对偶面积） | 1.854e-2 → 4.809e-3 → 1.208e-3 m² | **~1.97** |

- **为什么 `A_y` 是二阶而 `Lx/Lz` 是一阶**：`A_y = ¼dxdzΣv` 是"用 cell 面积分数做 2D 中点积分"，
  维度匹配 → 二阶；`Lx = ½dx(v(i−1,j)+v(i,j))` 是"用 **2D 面积分数**估计 **1D 线段开放长度**"，
  维度不匹配 → 一阶。
- **局部误差可到 0.5h**：在近切点（水平切线 z≈R 附近），真实开放长度 ≈0，而两侧 cell 的 volfrac 平均 ≈0.5
  → `Lx ≈ 0.5h`，即"半格"量级。这正好是"共形几何在 E 侧被方案 B 破坏"的直接证据（对应报告 R3）。
- **掩膜冻结**（报告 R1）：`ly==0`（任一相邻边全covered）的节点被冻结，但它们 `A_y>0`。几何统计：
  frozen-but-open 节点数 = **176 / 356 / 702**（40/80/160），约 **5.6 个/单位周长**（随 1/h 增长）；
  这些节点上的 E 更新是阶梯的 → 边界层一阶误差。
- **Yee 阶梯**（`c0`）：边界位置误差 O(h)，所以 `c0` 的 1.28 与 C 侧的 1.06 同属"一阶"范畴；
  C 侧没有更快收敛，是因为**它的一阶来源换了**（从阶梯换成方案 B 的线长度），而不是消失了。
- 界面场本身：Meep 文档明确"fields directly on the interface are still at best first-order accurate"
  （`Subpixel_Smoothing.md` limitation 4）。即便几何精确，界面上的场仍至多一阶；本项目的近场判据
  取 1.5R–2.5R 已经避开了界面，但误差由界面传播出来。

**结论**：只要 `Lx/Lz` 还是方案 B、掩膜还是 `ly`，C 侧就不可能到二阶。这与报告的 R1/R2/R3 判断一致，
本文把"为什么"量化到了具体量（`Lx/Lz` 绝对 RMS 与阶数、`A_y` 的对比、冻结节点数）。

### 5.2 测量层：有限分辨率下"入射波不是理想平面波"

真空对照（把 EB 移出域外、同一激光源、同一 40/80/160 三档），用无偏 LSQ 提取谐波后，
对 `exp(−iKz)` 做最小二乘平面波拟合，残差（相对幅度）：

| n | 真空平面波残差 |
|---|---|
| 40 | 0.828 |
| 80 | 0.210 |
| 160 | 0.147 |

即：**即便完全没有散射体**，160² 下"数值入射波"与解析平面波的偏差仍有 **~15%**。来源候选：
数值色散（k_num≠K，在 5λ 的拟合窗上积累相位）、PML 边缘/反射、激光源的有限开启过程。
这个地板会叠加在米氏 L2 上（160² 的 C 侧总误差 0.44，其中约 0.15 是地板），并**直接污染 RCS**：
RCS 用 `A_al − exp(iKZ)` 提取散射场，减的是**解析**入射，而不是同分辨率的**数值**入射，
于是把入射波的色散相位误差当成了散射场。

**RCS 阶数 ~1.76 的解释**：RCS 是远场积分量，边界层误差被角度平均（部分抵消），
剩余误差由"一阶边界 + 二阶色散/拾取污染"混合；三点拟合的局部阶数为 1.88/1.66（c0/c2），
本身就不是干净幂律。要判定渐近阶，需要：①减数值入射；②至少 4–5 档；③固定拟合窗与取样。

### 5.3 一句话回答

**不是"共形方法天生到不了二阶"，而是当前实现里：`Lx/Lz` 用 2D 面积分数估 1D 长度（一阶，局部半个胞）、
掩膜把一部分 cut 节点冻结（一阶）、Yee 阶梯本身一阶；再叠加"有限分辨率入射波不是理想平面波"（15% 地板）
和"RCS 减解析入射"这两个测量偏差，拟合出来就是 1.0–1.3。** 把 `Lx/Lz` 换成面分数（修正版方案 A）
或 level-set（方案 C）、把掩膜改成 `A_y<=0`、RCS 改减数值入射，才有希望看到接近 2 的阶。

## 6. 结论与建议

1. **报告可信**：代码/数字/结论与源码一致；L2a/L3 与米氏阶数全部复现；"残留问题"清单准确。
2. **先改 R5 的描述**（P1 文档级），并把"多层静默错误"写进已知限制；多层前先做"低层不分配或 assert"。
3. **阶数问题的优先级**：
   - R1（掩膜 `A_y<=0`）+ R3（`Lx/Lz` 换面分数或 level-set）是"把 C 侧真正变成二阶"的必要条件；
   - 测量侧：RCS 减**数值入射**（用同分辨率真空跑），并把真空残差（15%）当作误差地板报告；
   - 至少 4 档（40/80/160/320）再拟合阶数，避免三点拟合的局部波动。
4. **能量/守恒**：当前无一阶以上几何、无稳定化，E-1 类判据应分档（PEC 腔 + 解析腔模；无稳定化档 vs BCK 档）。
5. **下一步实验建议**（按性价比）：①`Lx/Lz` 改面分数（方案 A 修正）后重跑米氏三档；②掩膜改 `A_y<=0`；
   ③RCS 减数值入射；④把真空残差曲线作为"测量地板"固定进 CI。
