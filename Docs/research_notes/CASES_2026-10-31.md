## 1. C1：TM 正入射 PEC 平面（基线复算）

### 1.1 物理情景

2D XZ 平面，`x,z ∈ [−15, 15] m`，四边 PML。嵌入边界为 `z = 0` 的平面
（`eb_implicit_function = cos(α)(x−x0) + sin(α)(z−z0)`，`α = π/2` ⇒ 光滑地面），
PEC 占据 `z > 0`。初始条件是一束沿 `+z` 传播的 **TM** 脉冲：

```
Ex(z,0) = E0·exp(−((z−zc)/w)²)          E0 = 1e6 V/m, zc = −8 m, w = 1.5 m
By(z,0) = Ex(z,0)/c                      （单一传播方向，无反向分量）
```

探针 `fp_inc` 固定在 `(x,z) = (0, −5) m`。解析预测（正入射 PEC，`r = −1`）：

- 入射峰到达：`|−5 − (−8)|/c = 10.01 ns`
- 反射峰到达：`(8 + 5)/c = 43.36 ns`

### 1.2 数值设置

| 项 | 值 |
|---|---|
| 网格 | 384×384，`dx = dz = 30/384 = 0.078125 m` |
| 求解器 | `algo.maxwell_solver = ect`（EB 必须开） |
| 时间步 | CFL 0.4，`stop_time = 80 ns`（受 `stop_time` 控制） |
| 诊断 | `fp_inc` FieldProbe（每 2 步） |

### 1.3 结果

```
incident : t = 10.024 ns   Ex = +1.000021e+06 V/m   （解析 10.01 ns）
reflected: t = 43.488 ns   Ex = −9.993821e+05 V/m   （解析 43.36 ns）
r = −0.999361   |r| = 0.999361                     （PEC 期望 −1，误差 0.064%）
```

### 1.4 结论

- TM 偏振下 ECT 的 PEC 反射在**修复后仍正确**，且比修复前的 `−0.999295` 略优；
- 入射/反射时刻与解析值差 < 0.15 ns（≈ 0.3% 网格色散）。

复现：

```bash
cd benchmarks/cases/c02_0_pec
OMP_NUM_THREADS=8 ../../../../build_2d/bin/warpx.2d.MPI.OMP.DP.PDP.EB inputs_2d_tm_flat
python3 analyze_tm.py diags/reducedfiles/fp_inc.txt
```

## 2. C2：上游 2D ECT 回归（PEC 旋转立方体，TM）

### 2.1 物理情景

2D XZ，`[−0.8, 0.8]² m`，32×32 网格。嵌入边界是一个绕 y 轴旋转 `θ = π/8` 的立方体
（二维截面为旋转正方形，半宽 0.53 m，PEC）。初始条件为**腔模**：

```
By = μ0 · cos(mπ(x')/Lx) · cos(pπ(z')/Lz)     m = 0, p = 1, Lx = Lz = 1.06 m
```

`(x', z')` 为旋转后坐标。这是纯 **TM** 模（只有 `By` 非零），用来检查 2D ECT 在**真实 cut cell**
上的共形更新是否与上游一致。`max_step = 68`，`algo.maxwell_solver = ect`。

### 2.2 结果（plotfile `diag1000068`，`sum|Q|` 与上游 `Regression/Checksum` 基准比较）

| 分量 | 本 fork | 上游基准 | 相对差 |
|---|---|---|---|
| Ex | 7.8275781328e+04 | 7.8275781381e+04 | 6.78e-10 |
| Ez | 3.1681635821e+04 | 3.1681635842e+04 | 6.77e-10 |
| By | 2.7221007346e-04 | 2.7221007365e-04 | 6.78e-10 |
| Ey / Bx / Bz | 0（严格） | 0 | — |

### 2.3 结论

- fork 的 per-unit-y 改动、`idim<3`、掩膜改动**没有改变 2D TM 的数值行为**；
- `Bx`、`Bz` 仍严格为 0：TE 分量在 TM 初值下不会被激发，说明新增的 `Rhox`/`Rhoz` 通路在 TM 下确实闲置。

## 4. C4：L2a —— 规则域上 ECT 与 Yee 的逐位等价

### 4.1 物理情景

2D XZ，`[−8, 8]² m`，64×64（`dx = dz = 0.25 m`），四边 PEC。
**嵌入式边界被推到域外**（`eb_implicit_function = "z - 100"`），因此域内**没有任何 cut cell**，
ECT 的几何量处处均匀。初始条件为 **TE** 脉冲（`Ey` 出平面、`Bx` 入平面）：

```
Ey(z,0) = E0·exp(−((z−zc)/w)²)·cos(kz·z)      E0 = 1e6 V/m, zc = −5 m
Bx(z,0) = −Ey(z,0)/c                            w = 0.6 m, kz = 2.0944 rad/m（λ = 3 m）
```

`Bx = −Ey/c` 使脉冲单向沿 `+z` 传播；在 `t ≈ 45 ns` 时到达 `z = +8` 的 PEC 域壁并反射，
因此这段运行也覆盖了标准 PEC 边界路径。`max_step = 200`，CFL 0.4。

诊断：`fp1 (0,−1.5)`、`fp2 (0,+1.5)`、`fe`（FieldEnergy，每步）。

### 4.2 结果（ECT vs Yee，201 个采样点全量比较）

| 量 | 峰值 | `max\|d\|` | 相对差 |
|---|---|---|---|
| FieldEnergy total | 4.060209e+01 J | **0.000e+00** | 0 |
| FieldEnergy E | 3.069605e+01 J | **0.000e+00** | 0 |
| FieldEnergy B | 2.761955e+01 J | **0.000e+00** | 0 |
| fp1 Ey | 6.235032e+05 V/m | **0.000e+00** | 0 |
| fp1 Bx | 1.944326e-03 T | **0.000e+00** | 0 |
| fp2 Ey / Bx | 5.516750e+05 / 1.751397e-03 | **0.000e+00** | 0 |

`Ex/Ez/By/Bz ≡ 0`（两种求解器都一样）。

### 4.3 结论

- **两个求解器逐位相同**，不是"舍入级"而是严格的 0：per-unit-y 几何（`Sx=dz`、`Sz=dx`、`ly=1`）
  使 ECT 的面环量在代数上等于 Yee 的中心差分，连运算顺序都一致；
- 由此可以断言：**此前观测到的 0.55% 偏差 100% 来自初始化时序缺陷**（已修复）；
- 也说明 bulk（含 PEC 域壁）不存在格式差异，剩余差异只可能出现在 EB 界面 → 直接引出 C5。

复现：`./run_l2.sh`（第一段），或

```bash
python3 verify_l2a.py /tmp/l2/ect_noeb /tmp/l2/yee_noeb
```

## 5. C5：L2b —— 网格对齐 PEC 平面上的等效壁面位置

### 5.1 物理情景

与 C4 完全相同的域、网格、初值、诊断，唯一区别：嵌入边界就是 `z = 0` 平面
（`eb_implicit_function = "z"`），PEC 占据 `z > 0`，且**平面与网格严格对齐**（无切割单元，
只有"贴面"单元）。物理上应与 C4 的同一束 TE 脉冲在 `z = 0` 反射。

解析：入射峰 `(5−1.5)/c = 11.675 ns`；若壁在 `z = 0`，反射峰 `(5+1.5)/c = 21.682 ns`；
若等效壁面内移一层 `dz = 0.25 m`，则为 `20.014 ns`。

### 5.2 结果

**(a) 反射峰（探针 z = −1.5）**

| 求解器 | 入射峰 | 反射峰 | 与解析差 | `r = Ey_ref/Ey_inc` |
|---|---|---|---|---|
| ECT | 11.322 ns | **21.700 ns** | **+0.018 ns** | −0.9188 |
| Yee | 11.322 ns | 19.577 ns | −2.105 ns | −0.8505 |

ECT 的壁面在真实位置 `z = 0`，Yee 的壁面内移一层。

**(b) 全场能量（`fe`，201 步）**

| 量 | 峰值 | `max\|d\|` | 最大相对差 | 首次 >1e-12 | 首次 >1e-6 |
|---|---|---|---|---|---|
| total | 4.066723e+01 | 2.283e-01 | 5.6e-03 | step 33 | step 46 |
| E | 3.265870e+01 | 1.760e+01 | 5.4e-01 | step 31 | step 44 |
| B | 3.158899e+01 | 1.743e+01 | 5.5e-01 | step 30 | step 44 |

特征：**总能量几乎相同（0.56%），E/B 配比差异很大（54%）** ⇒ 相位/共振差异，不是能量不守恒。

**(c) 探针 fp1**

`Ey` 峰值 6.235032e+05 V/m，`max|d| = 7.362e+05`（相当于峰值的 118%，后期相位反相）；
首次显著差异出现在第 36 步（t ≈ 8.5 ns）。

**(d) 第 60 步场快照（plotfile，瞬时空间分布）**

| 分量 | 峰值 | `max\|d\|` | 相对差 | 差异最大位置 |
|---|---|---|---|---|
| Ey | 6.115e+05 | 2.133e+05 | 3.5e-01 | `z = −0.375` |
| Bx | 2.014e-03 | 1.211e-03 | 6.0e-01 | `z = −0.125` |
| Bz | 1.263e-03 | 1.600e-04 | 1.3e-01 | `z = −0.375` |
| Ex/Ez/By | 0 | 0 | — | — |

`Ey` 存在差异的 z 层共 25 层，最靠近壁面的三层为 `z = −0.62, −0.38, −0.12`，
即差异从壁面向后（−z）辐射，越靠近壁越大。

### 5.3 差异来源（已定位，详见 §7）

不是数值 bug，而是**掩膜约定**：

- AMReX 把"贴面"单元 `j=31`（`z ∈ [−0.25, 0]`）标记为 **cut**（`volfrac = 1`、`areafrac = 1`，但 `isRegular() = false`）；
- Yee 的 `MarkUpdateCellsStairCase` 用 `!isRegular()` 判据 ⇒ 冻结该层及其场点，等效壁面内移一层；
- ECT 用 `ly`/`face_areas`（由 `edge_cent`/`areaFrac` 得到的真实开放度）⇒ 只冻结壁面上的节点。

### 5.4 结论

- 原判据"对齐 PEC 上 ECT 必须逐位等于 Yee"**前提错误**（对齐面并不产生规则几何），已作废；
- 新判据 L2b 判定 **PASS**：`|t_ref(ECT) − t_analytic| = 0.018 ns ≤ 0.5 ns`，且 ECT 比 Yee 更接近解析；
- 两者相差一层 `dz` 属于**阶梯近似的 O(dx) 误差**，不是 fork 缺陷。

复现：`./run_l2.sh`（第二段），或

```bash
python3 verify_l2b.py /tmp/l2/ect_pec /tmp/l2/yee_pec
```

## 6. C5 的补充背景：为什么这个算例会"看起来像 bug"

最初的失败报告（`ECT_2D_TE_REPORT.md` §7.1）记录的是**修复前**的现象：

| step | 量 | ECT | Yee | 相对差 |
|---|---|---|---|---|
| 0 | total | 4.05301798772508e+01 | 4.05301798772508e+01 | 0 |
| 1 | total | 4.07538790237160e+01 | 4.05290908193397e+01 | +0.55% |
| 1 | E | 2.10499360613235e+01 | 2.02297715352119e+01 | +4.05% |
| 1 | B | 1.97039429623925e+01 | 2.02993192841279e+01 | −2.93% |

该指纹（第 0 步相同、第 1 步分叉、E 偏大/B 偏小且反号）是**半个时间步相位错位**，根因是
`EvolveECTRho` 在初始 E 场写入前就被调用 ⇒ `ρ ≡ 0` ⇒ 第一个半步 `B` 原地不动。
修复后同一算例第 0–20 步的总能量**逐位相同**（见 C4 的表），说明该指纹已消失；
C5 中剩下的差异全部来自掩膜（§5.3）。

## 7. C6：支撑性诊断实验（不单独产出物理结论）

### 7.1 E/B 更新掩膜（`m_eb_update_*`，沿 z 在 x 中心列统计）

| 求解器 | `Ey`（节点，`j ∈ [0,64]`） | `Bx`（`j ∈ [0,63]`） | `Bz`（`j ∈ [0,64]`） |
|---|---|---|---|
| ECT | 更新 `j = 0..31`（32 点），`first_zero = 32` | 更新 32 点，`first_zero = 32` | 更新 32 点，`first_zero = 32` |
| Yee | 更新 `j = 0..30`（31 点），`first_zero = 31` | 更新 31 点，`first_zero = 31` | 更新 31 点，`first_zero = 31` |

（`j` 为 z 方向索引，`j = 32` 对应 `z = 0`，即壁面。）

结论：Yee 比 ECT **多冻结一层**（`z = −0.25` 那一层）。

### 7.2 EB 单元标记（`z` 方向的单元，中心列）

| `j` | `z_lo` | `isRegular` | `isCovered` | `volfrac` | `areafrac[0]` |
|---|---|---|---|---|---|
| 28 | −1.00 | 1 | 0 | 1 | 1 |
| 29 | −0.75 | 1 | 0 | 1 | 1 |
| 30 | −0.50 | 1 | 0 | 1 | 1 |
| **31** | **−0.25** | **0** | **0** | **1** | **1** |
| 32 | 0.00 | 0 | 1 | 0 | 0 |
| 33 | 0.25 | 0 | 1 | 0 | 0 |
| 34 | 0.50 | 0 | 1 | 0 | 0 |

结论：`j=31` 几何上完全开放（`volfrac=1`）却被 AMReX 标为 cut ⇒ 两种掩膜判据在此处分道扬镳。

### 7.3 其他观察

- 该算例中 `Ey` 沿 `x` 并非严格不变：`x = ±8` 是 PEC 而初场在壁面上非零，产生边缘效应
  （`Ey` 在 `x` 最外一列约为内部的 1/2）；两种求解器表现一致，不影响对比结论；
- 因此 `Bz` 不为严格 0（峰值 1.26e-3 T，与 `Bx` 同量级），也属边缘效应，同样在两者中一致。

## 7bis. C7：L3 —— 30° 斜面 PEC 的反射（真 cut cell）

### 7bis.1 物理情景

2D XZ，`[−15, 15]² m`，384×384，四边 PML，`algo.maxwell_solver = ect`。
嵌入边界为斜平面 `cos α·(x−x0) + sin α·(z−z0) = 0`，`α = 30°`，PEC 在正侧——**这是本项目中唯一
真正切出 cut cell 的算例**（对齐面只产生"贴面"单元）。

初值：TE 无载波高斯脉冲，`Ey = E0·exp(−((z+8)/1.5)²)`，`Bx = −Ey/c`，沿 `+z` 入射。

镜面反射 `k̂_r = (−sin 2α, 0, cos 2α) = (−0.866025, 0, 0.5)`。6 个探针沿反射束布置：

| `fp_ref4` | (−3.464, 2.000) | 4 | 33.36 | 40.03 |
| `fp_ref5` | (−4.330, 2.500) | 5 | 35.02 | 43.36 |
| `fp_ref6` | (−5.196, 3.000) | 6 | 36.69 | 46.70 |
| `fp_ref7` | (−6.062, 3.500) | 7 | 38.36 | 50.03 |
| `fp_ref8` | (−6.928, 4.000) | 8 | 40.03 | 53.37 |

（另 `fp_inc (0,−5)`、`fp_shadow (0,+4)`——后者在导体内部，只用于校验 0 场。）

### 7bis.2 结果

| 探针 | `r = Ey_ref/Ey_inc` |
|---|---|
| `fp_ref3` | −0.9166 |
| `fp_ref4` | −0.9173 |
| `fp_ref5` | −0.9158 |
| `fp_ref6` | −0.9977 |

### 7quater.1 C12：PEC 圆柱散射（TE / TM）

#### 物理情景

- **几何**：2D XZ，`x,z ∈ [−5, 5] m`，`256×256`（`dx = dz = 10/256 = 0.0390625 m`）。
- **散射体**：半径 `R = 1 m` 的 PEC 圆柱，位于原点，

  圆柱周长约 160 个网格；脉冲中心波长约 `2w = 1.6 m`，`kR ≈ 4`（共振/衍射区）。

#### 发现的问题

**(a) 第一次运行所有外部探针为 0，柱心反而有噪声。**
首版写 `sqrt(x²+z²) − R`。WarpX 约定"正值为固体"，于是 `r > 1` 的**整个外部**都成了 PEC，
初始脉冲位于 `z = −3.5`（`r > 1`）落在导体内被清零；`r = 2 m` 的探针全为 0，
唯一"流体"点柱心反而读到数值噪声（`|Ey| ≈ 5e-3 V/m`）。
**排查链**：探针文件存在但全零 → 发现唯一非零探针在 `(0,0)` → 反推"非零区恰好 `r<1`" →
几何符号写反。改为 `R − sqrt(x²+z²)` 后一切正常。
**教训**：新几何先用"内部探针"验证符号。

**(b) TE 阴影衰减（81%）远强于 TM（30%）。**

阴影边界条件不同，且在 `kR ≈ 4` 的共振/衍射区前向衍射更强。**不能用"阴影更暗"判断精度**，
只能靠 Mie 定量对比。

**(c) TM 的 θ=90（1.075e6）高于镜面侧 θ=180（0.999e6）。**
几何光学预期镜面侧最强，但 TM 圆柱在该 `kR` 下侧向散射可超过前向。⇒ 判据只能用
"前后不对称"与"柱内为 0"，不能用"镜面侧最强"。

**(d) 缺 Mie 定量对比是本算例的明确缺口。**
入射脉冲无载波（宽谱，中心 `k≈0`），k 空间无法分离入射/散射，也无法与单频 Mie 级数逐点比较。
定量对比需要：(i) 加载波 `cos(k0 z)`（取 `k0 R ≈ 1–5`）；(ii) 在探针处 FFT 取 `ω0` 分量；
或 (iii) 连续波源（WarpX 无现成 TFSF）。这正是下一步"圆柱米氏收敛阶"要解决的。

#### 发现的问题

**(a) TM 10000 步后能量增长 1.9%，TE 只有 0.019%。**
两者差两个量级。TE 可视为舍入级；TM 的 1.9% 是系统性的（未发散、在 5% 阈值内，但说明
TM 在 cut cell 上不严格守恒）。可能机理（待验证）：

1. TM 的 `Rhoy = (Ez·lz|_i − Ez·lz|_{i+1} + Ex·lx|_j − Ex·lx|_{j+1})/Sy`，而 BCK 会把 `Sy`
   就地抬到 `S_stab`（`area_mod`），`Rho` 因此是欠松弛值；TM 有 Ex、Ez 两项参与，误差叠加，
   TE 只有 Ey 一项且几何量量级不同。
2. TM 的 B 更新（`By`）与 E 更新（`Ex`、`Ez`）在 cut cell 上用的面积/边长不一致，
   离散能量不再严格守恒。
3. `EvolveECTRho` 在 `AddExternalFields` 重算后，TM 初始 `By ≠ 0` 使首个半步环量与 B 不匹配
   （但 TE 的 `Bx ≠ 0` 也一样，可能性较低）。

这是 C 侧（E 场共形 Ampere）应解决的第一个精度问题，已写入报告 §14.6。

**(b) 峰值晚/早比 < 1 不代表"衰减"，而是脉冲离开了探针。**
域内 PEC 壁来回反射，探针 `(0,−1)` 不在所有回路上，峰值自然下降。只能作为"无增长"的必要条件。

**(c) 10000 步不足以判断 1.9% 是单调增长还是趋于平台。**
需更长时间（如 5×10^4 步）或对能量时间序列做趋势拟合；本轮只记录 `Emax/E0` 与末端漂移。

## 7quinquies. C15：圆柱米氏散射收敛阶（原记录：被"小胞元不稳定"阻塞）

> **2026-10-31 晚更正**：本节 §7quinquies.4/§7quinquies.5 的根因判断（"曲边界极小 volfrac 胞元 + 
> E 侧阶梯掩膜"）**已被实验推翻**。真正原因是 `amr.max_grid_size = 64 < n_cell = 80` 造成的多 grid
> 分解（CW 激光源跨 grid 不稳定），与 EB / ECT / E 侧阶梯**全部无关**。
> 单 grid 下米氏三档全部稳定，收敛阶已测出。详见 **§7sexies**。

> 结论先行：**收敛阶测不出来**。40² 档（`dx = 0.2 m`）稳定，80² 档（`dx = 0.1 m`）起场在
> 数十步内爆到 `1e306–1e308`，把 CFL 从 0.4 降到 0.2 / 0.1 仍然爆。根因指向"E 侧仍是阶梯 +
> B 侧共形"在曲边界极小胞元处的不一致（即 C 侧缺失），与 `M2A_CODE_AUDIT.md` 的 P1 判断一致。

### 7quinquies.1 物理情景与设置

- **几何**：2D XZ，`[−4, 4]² m`，PEC 圆柱 `R = 1 m` 在原点，`eb = R − sqrt(x²+z²)`，四边 PML。
- **入射**：**连续时谐平面波**，沿 `+z`，`λ = 1 m`（`k = 2π`，`ka = 6.283`），`E0 = 1e6 V/m`。
  用自定义激光 profile 产生（源码依据：`Source/Laser/LaserProfilesImpl/LaserProfileFieldFunction.cpp`
  用 `ParserExecutor<3>`，变量为 `{X,Y,t}`，返回值即场幅值）：

  ```
  lasers.names = laser1
  laser1.profile = parse_field_function
  laser1.field_function(X,Y,t) = "E0*cos(omega*t)"
  laser1.position = 0.0 0.0 -3.0
  laser1.direction = 0.0 0.0 1.0
  laser1.polarization = 0.0 1.0 0.0      # E ∥ 轴（Ey）；TM 版用 1 0 0（Ex/By）
  laser1.wavelength = 1.0
  ```

- **分辨率阶梯**（相邻 2 倍，跨 16 倍）：`n_cell = 40, 80, 160, 320, 640`
  → `dx = 0.2, 0.1, 0.05, 0.025, 0.0125 m`。
- **时间**：`stop_time = 45 ns`（约 13 个周期），`CFL = 0.4`；每 `T/8` 输出一帧全场
  （`d1.fields_to_plot = Ey` 或 `By`），取最后 8 帧做 **8 点 DFT** 提取 `ω0` 复振幅。
- **后处理**（`analyze_mie_convergence.py`）：
  1. 8 帧 DFT 得复振幅 `A(x,z)`；
  2. 与 Mie 解析总场做**全局相位对齐**（平面波参考任意）；
  3. 近场 L2：`‖A−A_Mie‖₂/‖A_Mie‖₂`，区域 `1.5R ≤ r ≤ 2.5R`；
  4. RCS：在 `r = 2R` 圆上取散射场（总场 − 入射），柱谐投影得 `c_n`，外推到远场
     `σ(φ) = (4/k)|Σ j^n c_n e^{jnφ}|²`，与 Mie 的 `σ(φ)` 比 L2；
  5. `log(err)` vs `log(dx)` 线性拟合得阶数。

### 7quinquies.2 Mie 参考解（已实现并自检）

`mie_cylinder.py`（`scipy.special.jv/hankel1`）：`e^{-jωt}` 约定，外向波 `H_n^(1)`；θ 从 `+z` 量起。

```
E ∥ 轴：E_y = E0 Σ j^n [J_n(kr) − a_n H_n^(1)(kr)] e^{jnθ},  a_n = J_n(ka)/H_n^(1)(ka)
E ⊥ 轴：B_y 同上，b_n = J_n'(ka)/H_n^(1)'(ka)
σ(φ) = (4/k)|Σ j^n c_n e^{jnφ}|²
```

自检结果（`ka = 6.283`，`n_max = 22`）：

| 检查 | 结果 |
|---|---|
| PEC 表面 `\|E_y(r=a)\|` | `1.27e−08`（应为 0）✓ |
| `E ⊥` 时 `\|dH_y/dr\|_{r=a}` | `7.55e−10`（应为 0）✓ |
| `⟨σ⟩_φ` vs `(4/k)Σ\|a_n\|²` | `4.579961` vs `4.579961`，相对差 `0.0` ✓ |
| 远场 `2πr\|E_s\|²` → `σ(φ)` | `r=100/1000/10000` 时相对差 `1.1e−2/1.1e−3/1.1e−4`（1/r 收敛）✓ |

### 7quinquies.3 测试结果：细网格爆炸

| 档 | dx (m) | 环内 `max\|E\|`（末帧） | 状态 |
|---|---|---|---|
| 40² | 0.2000 | `1.60e+06` | 正常 |
| 80² | 0.1000 | `2.26e+306` | **爆炸** |
| 160² | 0.0500 | `1.70e+308` | **爆炸**（环内已有 3 个 NaN） |

CFL 扫描（80² 档，末帧环内 `max|E|`）：

| CFL | 结果 |
|---|---|
| 0.4 | `2.26e+306` |
| 0.2 | `2.80e+306` |
| 0.1 | `1.17e+308` |

⇒ **降低 dt 无效**，不是 CFL 不足，而是结构性的增长模式。

对照：同一实现的 45° 斜面 128²（`dx = 0.125 m`）跑 10000 步稳定（C14），说明问题**不是**
"细网格"本身，而是**曲边界产生的极小体积分数胞元**。

### 7quinquies.4 问题定位

1. 圆柱曲边界在 `dx ≤ 0.1` 时产生 `volfrac ~ 1e−3` 甚至更小的胞元；
2. B 侧（Faraday）是共形的：`S` 被 BCK 抬到 `S_stab`，`Rho = ∮E·dl/S_mod` 是欠松弛值；
3. E 侧（Ampere）仍是**阶梯掩膜**：极小胞元内的 E 点被直接跳过，不参与更新；
4. 于是 B 用放大后的面积继续演化、E 却不响应 ⇒ 局部的"单向增益"，在细网格（更多极小胞元）上迅速放大。

这与 `M2A_CODE_AUDIT.md` P1（E 侧未共形）与 P2（BCK-only、小胞元未扫描）的判断一致，
也解释了为什么 45° 平面（无极小胞元）稳定、圆柱（有）不稳定。

### 7quinquies.5 结论与下一步选项

- **无法给出收敛阶**：只有 40² 一档可用，单点无法拟合 `log(err)–log(dx)`；
- 这不是 Mie 实现或激光源的问题（两者都已自检/验证），而是**求解器在曲边界小胞元上不稳定**；
- 可选路径：
  1. **先做 C 侧（E 场对偶共形 Ampere）**，让 E/B 在小胞元上同步 —— 预期能消除该增长模式，
     再做 5 档收敛阶（这是原计划，也是 `C_SIDE_DESIGN.md` 的目标）；
  2. 或在现有实现上**加"最小体积分数过滤"**（把 `volfrac < 1e−3` 的胞元并入邻胞/阶梯化），
     作为工程稳定化，但会引入 O(dx) 误差、破坏收敛阶测量；
  3. 或改用**无极小胞元的几何**（如网格对齐的多边形柱、或球/方柱）做收敛阶，但那不再是
     曲边界 Mie 验证。

python3 mie_cylinder.py              # Mie 级数自检
# 逐个跑到 /tmp/mie/<pol>_<n>/ 后：

## 7sexies. C16：C 侧对偶共形 Ampere 的验证，以及米氏根因更正

> 2026-10-31 晚。实现 `algo.ect_conformal_E` 后重跑三个算例族；本节同时推翻 §7quinquies 的根因判断。

### 7sexies.1 物理情景与开关

- **新开关**：`algo.ect_conformal_E = 0`（旧掩膜 Yee，默认）/ `1`（常数几何，调试用）/ `2`（真实对偶几何）。
- **新增几何量**（2D XZ，由 `volfrac` 组装，方案 B）：
  - `A_y`（节点，与 `Ey` 同位）`= ¼ dx dz Σvolfrac`；
  - `Lx`（与 `Bx` 同位）`= ½ dx [v(i-1,j)+v(i,j)]`；
  - `Lz`（与 `Bz` 同位）`= ½ dz [v(i,j-1)+v(i,j)]`。
- **内核**（`EvolveECartesianECT`）：

```
Ex += −c²dt [By(i,j) − By(i,j-1)] / Lz(i,j)
Ez += +c²dt [By(i,j) − By(i−1,j)] / Lx(i,j)
Ey += +c²dt [Bx(i,j)Lx(i,j) − Bx(i,j−1)Lx(i,j−1)
             −Bz(i,j)Lz(i,j) + Bz(i−1,j)Lz(i−1,j)] / Ay(i,j)
```

- **算例**：L2a（`inputs_ect_2d_noeb`，64²，200 步）、L3 45° TE（`inputs_2d_oblique_te_45deg`，384²）、
  米氏 C15（`inputs_mie_ey_{40,80,160}`，单 grid）。

### 7sexies.3 发现一："逐位一致"在共形格式下不可能

L2a 的判据原写 `max|d| = 0`，实测 `max|d| ≈ 1e-9`（相对 1.6e-15）。原因不是索引错：

```
Yee : (Bx(i,j) − Bx(i,j-1)) / dz
共形: (Bx(i,j)·dx − Bx(i,j-1)·dx) / (dx·dz)
```

数学等价，但"先乘后减再除" ≠ "先减后除"。**任何"乘开放长度再除对偶面积"的形式都不可能逐位等于差商**。
C-1 的正确表述是 `rel ≤ 1e-14`。

副产物：TE 的 `Bz` 峰值只有 1e-19（纯舍入），旧判据给出 `rel = 1.0` 的假 FAIL；`verify_l2a.py`
已加噪声地板（`1e-13 × 其它分量的峰值`）。

### 7sexies.4 发现二：米氏爆炸的根因是多 grid，不是小胞元

80²、400 步、`update` 到同一时刻，逐项隔离（`max|E|` 为末帧）：

| 配置 | `max_grid_size` | 末帧 `max\|E\|` |
|---|---|---|
| ECT + EB 圆柱 + 掩膜 Yee | 64（4 grid） | 1e306（数十步即爆） |
| ECT + EB 圆柱 + 共形 E（常数几何） | 64 | 1.03e308 |
| ECT + EB 圆柱 + 共形 E（真实几何） | 64 | step 64 已 5.8e307 |
| ECT + EB 移出域外 + 共形 E | 64 | 1.36e308 |
| **Yee + EB 移出域外 + PML** | 64 | **1.67e308** |
| **Yee + EB 移出域外 + PEC** | 64 | **1.46e308** |
| ECT + 无 EB | **80（1 grid）** | **1.25e6** |
| ECT + 共形 E + 无 EB | **80（1 grid）** | **1.25e6** |
| Yee + 无 EB | **80（1 grid）** | **1.25e6** |
| ECT + **EB 圆柱** + 掩膜 Yee | **80（1 grid）** | **1.92e6** |
| ECT + **EB 圆柱** + 共形 E | **80（1 grid）** | **1.86e6** |
| 同第 4 组但源幅值置零 | 64 | 2.88e6（稳定） |

判据是**单/多 grid 的分界**，与 EB、ECT、PML、E 侧阶梯、C 侧全部无关。

这同时解释了历史现象：40²/64² 时 `max_grid_size = 64 ≥ n_cell`（单 grid）稳定，80²/160² 被切块就爆。

**修正**：`make_mie_cases.py` 模板改为 `amr.max_grid_size = {n}`。

### 7sexies.5 发现三：米氏后处理的两个 bug

1. **相位参考错**：DFT 用 `exp(i·ω·j·T/8)`，但帧间隔是整数步（40² 时 `interval = 2`，与 `T/8` 差 12%），
   累积相位误差约 34°，相位在 −142°/+155°/+149° 之间跳。改为读 plotfile `Header` 第 5 行的物理时间。
2. **未归一化**：数值场是 V/m（`E0 = 1e6`），解析场幅值为 1，L2 误差被 `E0` 支配（恒为 `1e6`，阶数 0）。
   改为除以 `my_constants.E0`。

### 7sexies.6 结论

- C 侧在**规则域**上与 Yee 到机器精度一致，实现正确；
- 在 45° 斜面与米氏上，**一阶对偶几何与阶梯同阶**（近场 1.06 vs 1.28），要兑现精度必须换
  level-set 精确几何（方案 C）；
- 米氏"不稳定"是配置问题，不是物理/格式问题，**C 侧不背这个锅**；
- 遗留：掩膜未按新语义调整（`ly == 0` 仍冻结部分 cut 节点）、无对偶稳定化、3D/AMR 未做。
- **AMR 的真实后果（2026-10-31 复核更正）**：三套几何量的分配初值是 `1.0_rt`，而
  `ComputeDualGeometry` 只在 `maxLevel()` 调用 → 多层时低层保持 **1.0**，内核 `÷1.0`，
  即**量纲错、静默错误更新**（不冻结、不 abort、不除零）。原先"几何为 0 → 除零保护 → 冻结"的
  说法是错的，见 `C_SIDE_REPORT_CHECK.md` §3 与 `C_SIDE_FIX_PLAN.md` F2（已改为 `maxLevel()==0` 断言）。

## 8. 失败与作废的实验（避免重犯）

> 每条给出：触发条件 → 观测现象 → 排查过程 → 根因 → 修正 → 教训。全部为本轮实际踩过。

### 8.1 `probe_geometry = Line` 在本 2D 构建下返回全 0

- **触发**：想用一条沿 z 的线探针（65 点，`interp_order = 0`）一次取整个剖面，代替逐点点探针。
- **现象**：`lp.txt` 写出 12864 行（201 步 × 64 点），时间与坐标列正确，但
  **Ex/Ey/Ez/Bx/By/Bz 六列全为 0**；同一次会话中的点探针（`probe_geometry = Point`）正常。
- **排查**：先用线探针对比 ECT 与 Yee，得到"`max|d| = 0`，完全一致"的结论；
  后来检查单个探针文件的绝对值（`max|Ey| = 0.0`），才发现两者都是全零，
  所谓"一致"是**两个空信号相等**。这是本轮最危险的假阴性。
- **根因**：该 2D 构建下 Line 几何的场采样未生效（与插值/粒子形状实现有关），未继续深究。
- **修正**：放弃线探针；空间定位改用 `diag_type = Full` 的 plotfile 快照
  （`benchmarks/plotfile_checksum.py` 的读取方式），时间序列改用"沿束布多个点探针"。
- **教训**：任何"完全一致"的结论，先确认信号非零（打印 `max|·|`，不要只看差值）。

### 8.2 配置错配导致的假差异（ECT 无 EB vs Yee 有 EB）

- **触发**：为隔离 EB 影响，把 ECT 侧隐函数改成 `z - 100`（EB 移出域外），Yee 侧仍用 `z`。
- **现象**：`FieldEnergy` 出现 `max|d| = 2.28e-1`、相对 `5.6e-3` 的"差异"，一度被当作
  ECT 与 Yee 的真实偏差写进结论。
- **排查**：`diff` 两份输入，发现只有 `warpx.eb_implicit_function` 不同。
- **根因**：一个算例有 PEC 平面、另一个没有，物理问题不同。
- **修正**：双方都移出 EB（L2a 算例），差异变为严格的 0（201 步全 0）。
- **教训**：对比实验先 diff 输入；"我记得一样"不算证据。

### 8.3 圆柱 EB 符号写反，整个外部变成导体

- **触发**：`warpx.eb_implicit_function = "sqrt(x^2+z^2) - R"`。
- **现象**：8 个 `r = 2 m` 探针全程 `|E| = 0`；柱心 `pin` 反而有 `|Ey| ≈ 5e-3 V/m`。
- **排查**：文件有数据但全零 → 唯一的非零探针在 `(0,0)` → 反推"非零区恰好是 `r < 1`" →
  说明 `r > 1` 被判成固体。
- **根因**：WarpX/AMReX 约定**隐函数为正的一侧是固体**；`sqrt(·) − R` 在外部为正。
- **修正**：改为 `R - sqrt(x^2+z^2)`；修正后柱内严格 0、外部按物理分布（§7quater.1）。
- **教训**：新几何先放一个"内部探针"验证符号，再跑大算例。

### 8.4 `hypot` 丢符号，反射系数恒为正

- **触发**：`analyze_oblique.py` 首版用 `math.hypot(0.0, Ey)` 取振幅。
- **现象**：TE 的 6 个探针 `r = +0.9166 … +1.1135`，判据 `|r+1| ≈ 2`，六组组合一律 FAIL。
- **根因**：`hypot` 返回非负值，PEC 的相位反转（`r = −1`）信息丢失。
- **修正**：TE 用**带符号**的 `Ey` 峰值（`peak_in` 按 `|Ey|` 选点、返回带符号值）；
  TM 才用 `|Ex,Ez|` 幅值，目标改为 `+1`。
- **教训**：振幅与相位分开判；`r` 的符号是 PEC 反射最核心的物理。

### 8.5 峰值搜索窗口取 `0.6·t_max`，误取二次反射

- **触发**：`verify_l2b.py` 首版用"时间轴 60% 之后的最大值"当反射峰。
- **现象**：64² 上取到 30.898 ns（一次反射应在 21.7 ns，30.9 ns 是二次反弹），
  `r = −0.372`、判定 FAIL。
- **根因**：闭腔存在多次反射，纯"时间分割"无法区分一次与二次反射。
- **修正**：用解析入射/反射时刻锚定窗口（`t_ref ± 0.4·(t_ref − t_inc)`）；
  并在 L2b 中把判据改为**往返时间**（`t_ref − t_inc`），消除载波相位随 `dz` 的漂移
  （详见 `M2A_CODE_AUDIT.md` §0.1）。
- **教训**：闭腔内的峰值检索必须用解析时刻或到达时间排序，不能靠固定时间比例。

### 8.6 掠入射（15°）峰值法失效

- **触发**：`make_l3_angle.py 15` 生成掠入射算例。
- **现象**：平均 `r = −0.4239`，6 个探针从 `+0.3347` 到 `−0.7141`，符号都不统一。
- **排查**：计算入射与反射在探针处的时间间隔 `(s − z_P)/c`，只有 1.3–3.6 ns；
  而脉冲包络半宽约 `2w/c = 3 ns` —— 两个脉冲重叠，峰值比无意义。
- **根因**：掠入射下反射束几乎与入射同向。
- **修正**：删除该算例（不留误导性输入），文档记录"需更窄脉冲（`w ≤ 0.4 m`）或更大域"。
  同类问题在 30° 的 TM 上以"横向性 0.446"的形式再次出现（§7quater.2）。

### 8.7 圆柱 CW 米氏算例在 dx ≤ 0.1 时爆炸（不是设置错误）

- **触发**：`inputs_mie_{ey,by}_{80,160}`（CW 激光平面波 + PEC 圆柱，`dx = 0.1 / 0.05`）。
- **现象**：40² 档正常（环内 `max|E| ≈ 1.6e6`），80² 起末帧环内 `max|E| ≈ 1e306–1e308`，
  160² 环内出现 NaN；把 CFL 从 0.4 降到 0.2 / 0.1 **仍然爆炸**。
- **排查**：① 确认 plotfile 尺寸与 Header 一致（`80×80×8 B + 332 B = 51532 B`），排除读取错位；
  ② 检查 NaN 分布（covered 区与环内都有）；③ 换用初值脉冲（无激光）同样爆炸，排除激光源；
  ④ 对照 45° 斜面 128²（`dx=0.125`）10000 步稳定 ⇒ 不是"细网格"本身；
  ⑤ 定位到曲边界极小体积分数胞元 + E 侧阶梯掩膜。
- **根因（2026-10-31 晚更正）**：**不是**小胞元，而是 `amr.max_grid_size = 64 < n_cell = 80` 造成的
  4 个 grid；CW 激光源跨 grid 不稳定。同一算例单 grid 下稳定在 `1.9e6`（含 EB 圆柱），
  Yee + PEC + 无 EB 也照样爆。见 §7sexies.4。
- **修正**：`amr.max_grid_size = n`（单 grid）。C 侧（共形 E）**不能**修这个问题。
- **教训**：① 稳定性排查要先把"网格分块"当作独立变量（`max_grid_size` 与 `n_cell` 的关系），
  否则会把配置问题误判为格式缺陷；② 单/多 grid 的判据比"分辨率"更贴合这次的边界；
  ③ "降 CFL 能救"是错的直觉（实测 0.4→0.1 全爆）。

### 8.8 `laser1.profile = parse_field_function` 是可用 CW 源（正面记录）

- **背景**：原先以为 WarpX 没有连续平面波源，只能用"宽脉冲 + FFT"近似。
- **事实**：`Source/Laser/LaserProfilesImpl/LaserProfileFieldFunction.cpp` 用
  `ParserExecutor<3>`，变量为 `{X,Y,t}`，`fill_amplitude` 直接把返回值当**场幅值（V/m）**。
- **验证**：`field_function(X,Y,t) = "1.0e6*cos(omega*t)"` + `polarization = 0 1 0`
  在 2D ECT 下给出 `max|Ey| = 1.05e6`、`Bx/Ey = 3.07e-9 ≈ 1/c`，自洽。
- **用途**：C15 的时谐源就是它；也可用于任何需要 CW 的验证算例。

### 8.9 把"E 侧阶梯"当成米氏爆炸的根因（归因错误，代价一周）

- **触发**：80² 圆柱算例爆炸，恰好 `volfrac` 最小到 1e-3，且 E 侧确实是掩膜 —— 因果看起来完美。
- **现象**：写进 `HANDOFF.md` §3 与两份设计文档，作为"必须做 C 侧"的论据；C 侧实现后仍爆。
- **排查**：把 EB 移出域外（仍爆）→ 换 Yee（仍爆）→ 换 PEC（仍爆）→ 源置零（稳定）→
  改 `max_grid_size = n`（稳定）。六步才定位到多 grid。
- **根因**：**相关性 ≠ 因果**。`volfrac` 小与爆炸同时出现，只是因为两者都随 `dx` 变化。
- **修正**：`make_mie_cases.py` 改单 grid；`HANDOFF.md` §3 与 §7quinquies 已订正。
- **教训**：稳定性问题先做"消元"（EB、求解器、边界、源、分块），每次只改一个变量；
  在拿到"单变量对照表"之前，不要把它写进设计文档当既定事实。

### 8.10 米氏后处理的两个静默错误（L2 恒为 1e6、相位跳 34°）

- **触发**：`analyze_mie_convergence.py` 跑出的近场 L2 恰好等于 `E0 = 1e6`，阶数 0.00。
- **现象**：三档的 L2 都是 1.0e6 量级，相位 −142.7°/+155.7°/+149.2°，看起来像"完全不收敛"。
- **根因**：① 数值场（V/m）未除以入射幅值，误差被 `E0` 支配；② DFT 相位用 `j·T/8`，
  而帧间隔是整数步（40² 时 2 步，与 `T/8` 差 12%），8 帧累积约 34°。
- **修正**：除以 `my_constants.E0`；相位改用 plotfile `Header` 的物理时间。
- **教训**：**判据脚本也要做量纲/归一化自检**——如果 L2 误差恰好等于某个输入常数，
  先怀疑归一化；如果相位随分辨率跳变而幅值正常，先怀疑时间参考而不是物理色散。

## 9. 结论小结

1. **TM 与 3D 全部正常**：C1 `r = −0.9994`、C2 2D 回归 6.8e-10、C3 3D 回归 ≤1e-13；
2. **规则域上 2D TE 的共形格式与 Yee 逐位等价**（C4，`max|d| = 0`，含 PEC 域壁反射）；
3. **网格对齐 PEC 上两者必然不同**（C5）：ECT 壁面在真实位置（误差 0.018 ns），Yee 内移一层 `dz`
   （误差 −2.1 ns）；差异来源是"贴面 cut cell"的掩膜约定（C6），不是实现缺陷；
4. 因此 L2 判据被订正为 L2a（逐位退化）+ L2b（壁面位置），二者均 PASS；
5. 尚未覆盖：30° 斜入射（L3，探针布置需先修正）、AMR 多层、2D/3D 逐点一致性。

**2026-10-31 晚追加（C16 / §7sexies）**

6. **C 侧（对偶共形 Ampere）已实现**：规则域与 Yee 到机器精度（`rel ≈ 2e-15`，不是逐位 0，
   原因见 §7sexies.3）；45° 斜面斜率误差 2.39% → 1.51%，幅值 0.0427 → 0.0459；
7. **米氏已解锁**：根因是多 grid（`max_grid_size`），不是小胞元；修正后 TE 近场收敛阶
   掩膜 Yee 1.28、共形 E 1.06，RCS 分别为 1.76 / 1.77 —— 一阶几何与阶梯同阶，
   要提升需 level-set 精确几何（方案 C）；
8. **C 侧尚未闭合的三项**：掩膜仍按 `ly == 0` 冻结部分 cut 节点、无对偶稳定化（`A_stab`）、
   3D 与 AMR 未实现。
