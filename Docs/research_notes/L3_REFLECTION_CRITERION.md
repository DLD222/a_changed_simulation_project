## 1. 旧判据为什么无效

旧 `inputs_2d` 的两个探针是 `fp_inc (0,−5)` 与 `fp_shadow (0,+4)`。

斜面 `cos α·x + sin α·z = 0`（α=30°，PEC 在正侧）在 `x = 0` 处的壁面是 `z = 0`，
因此 `(0, +4)` **落在导体内部**，那里场恒为 0；它既不是反射探针，也不在反射束上。
把它当作"反射探针"得到的 `r = −0.531` 只是数值噪声/绕射泄漏的比值，**无物理意义**。

## 2. 反射几何（判据的基础）

入射沿 `+z`：`k̂_i = (0, 0, 1)`；壁面法向 `n = (cos α, 0, sin α)`。

```
k̂_r = k̂_i − 2 (k̂_i·n) n = (−sin 2α, 0, cos 2α) = (−0.866025, 0, 0.5)   (α = 30°)
```

即反射束从镜面点 `(0,0)` 出发，朝 `−x / +z` 方向。对反射束上弧长 `s` 处的探针 `P`：

```
s     = −(n·P)/sin α                    （由 n·(P − s k̂_r) = 0 解出）
z_W   = z_P − s·cos 2α                   镜面点 W 的 z 坐标
t_inc = (z_P − z_pulse)/c                入射峰通过 P 的时刻
t_ref = (z_W − z_pulse)/c + s/c          反射峰通过 P 的时刻
```

取 `z_pulse = −8 m`、`s = 3..8 m`，得下表（探针均由脚本按上式布置，`inputs_2d_l3` 中为数值）：

| 探针 | `(x, z)` m | `s` m | `t_inc` ns | `t_ref` ns |
|---|---|---|---|---|
| `fp_ref3` | (−2.598, 1.500) | 3 | 31.69 | 36.69 |
| `fp_ref4` | (−3.464, 2.000) | 4 | 33.36 | 40.03 |
| `fp_ref5` | (−4.330, 2.500) | 5 | 35.02 | 43.36 |
| `fp_ref6` | (−5.196, 3.000) | 6 | 36.69 | 46.70 |
| `fp_ref7` | (−6.062, 3.500) | 7 | 38.36 | 50.03 |
| `fp_ref8` | (−6.928, 4.000) | 8 | 40.03 | 53.37 |

另有 `fp_inc (0,−5)`（入射参考）与 `fp_shadow (0,+4)`（导体内部，校验应为 0）。

> 入射波是 `exp(−((z+8)/1.5)²)` 的**无载波**高斯脉冲，因此 2D 波谱分解不可行
> （入射与反射的 k 都在原点附近、谱严重重叠）。判据只能在时域上做，故选沿束多探针。

## 3. 结果（ECT，384×384，CFL 0.4，800 步，PML 四边）

| 探针 | `r = Ey_ref / Ey_inc` |
|---|---|
| `fp_ref3` | −0.9166 |
| `fp_ref4` | −0.9173 |
| `fp_ref5` | −0.9158 |
| `fp_ref6` | −0.9977 |
| `fp_ref7` | −1.1135 |
| `fp_ref8` | −1.0649 |
| **沿束平均** | **−0.9876**（`\|r+1\| = 0.0124`） |

- 所有探针 `r < 0` ⇒ **相位反转**，与 PEC 一致；
- 导体内部 `max|Ey| = 0.000e+00`；
- 单点值在 `−0.92 .. −1.11` 之间起伏（±10%）。

## 4. 起伏不是离散误差：384² vs 768²

| 分辨率 | `r(fp_ref5)` | `r(fp_ref7)` |
|---|---|---|
| 384²（800 步） | −0.9158 | −1.1135 |
| 768²（1600 步） | −0.9146 | −1.1142 |

两者相差 < 0.0015，**几乎没有分辨率依赖** ⇒ 起伏来自几何/边界（有限斜面被 PML 截断后
在束上形成的衍射调制），不是共形格式的收敛性问题。

## 5. 与 Yee 的对照（说明起伏不是 ECT 特有）

Yee + PML 在本算例下会 abort：WarpX 的投影 div(B) 清洁器要求边界为 periodic/PEC/PMC/neumann，
PML 不满足。因此 Yee 对照改用 **PEC 域边界**（此时反射波最早在 `2×(15−3.5)/c ≈ 77 ns` 才从
域壁返回，晚于全部探针窗口，不干扰测量）：

| 探针 | ECT（PML） | Yee（PEC 边界） |
|---|---|---|
| `fp_ref3` | −0.9166 | −0.9176 |
| `fp_ref4` | −0.9173 | −0.9183 |
| `fp_ref5` | −0.9158 | −0.9195 |
| `fp_ref6` | −0.9977 | −1.1005 |
| `fp_ref7` | −1.1135 | −1.3306 |
| `fp_ref8` | −1.0649 | −1.2672 |
| **平均** | **−0.9876** | **−1.0756** |

两者的`r(s)` 起伏**形态相同**（`s ≤ 5` 约 −0.92，`s ≥ 6` 抬升），Yee 的偏离更大。
⇒ 起伏是"有限斜面 + 外边界"的几何效应，不是 ECT 的共形误差；ECT 的沿束平均反而更接近 −1。
（两者边界条件不同，此对照只用于定性判断起伏来源，不作精度排名。）

## 5bis. 角度扩展：60° PASS，15° 方法不可用

`make_l3_angle.py <angle>` 由 `inputs_2d_l3` 生成任意角度的算例（探针按
`k̂_r = (−sin2α, cos2α)` 自动布置）。

**60°**（`inputs_2d_l3_60deg`，`k̂_r = (−0.866, −0.5)`，反射朝 −x/−z）：

| 探针 | 3 | 4 | 5 | 6 | 7 | 8 | 平均 |
|---|---|---|---|---|---|---|---|
| r | −0.9993 | −1.0047 | −1.1496 | −1.0549 | −1.0315 | −1.0201 | **−1.0434** |

`|r+1| = 0.0434` → PASS（阈值 0.05）；单点起伏 ±5%，比 30° 的 ±10% 更小。

**15° 不可用**：`k̂_r = (−0.5, 0.866)` 与入射 `+z` 只差 30°，反射与入射在探针处的时间间隔
`(s − z_P)/c` 仅 1.3–3.6 ns，小于脉宽（`w = 1.5` → ~3 ns），两个脉冲在时域重叠，峰值法失效
（实测平均 r = −0.42，不是物理错误）。需要更窄的脉冲（`w ≲ 0.4 m`）或更大的计算域才能测掠入射。

## 8. 局限与后续

1. **只用了时域峰值比**。斜入射的严格判据应是能量通量守恒（`∫S·n` 在束截面上积分）
   或反射/透射的波谱分解——后者需要给脉冲加载波（当前无载波，k 空间不可分）。
2. 单点起伏 ±10% 说明"用单探针做判据"不可靠，这也是旧判据容易误判的原因之一。
3. 建议后续把 L3 扩展为：给初值加 `cos(k0 z)` 载波（λ≈3 m）+ 2D FFT 分离
   `(k_x, k_z)` 两峰，直接核对反射角 `2α` 与幅值。这需要新算例（`inputs_2d_l3_spectral`）。
4. 仍未覆盖：TE 斜入射与 TM 斜入射的对比、AMR 下的斜面、以及 C 侧（E 场共形 Ampere）
   接入后的复测（届时 `r` 应有可见改善）。
